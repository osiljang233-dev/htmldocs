# step138 — KBO 픽 카드에 지표 타일 채우기

KBO 픽 카드가 텅 비어 있다. 근거가 20개나 들어오는데 화면엔 "8/20" 막대 하나뿐이고
지표 타일이 0개다. MLB 카드엔 지표 4타일이 뜨는데 KBO는 아무것도 안 뜬다.

원인은 하나 — 지표 타일을 만드는 블록이 «홈/원정 승률» 요약문(MLB 형식)일 때만 돌아간다.
KBO 요약문은 "롯데 승률 66%"(팀 이름)라 그 정규식에 안 걸려서 블록이 통째로 안 돈다.

**이번 건은 `News.php` 한 파일, 한 곳에 블록 하나 삽입이야.**
base 는 116,772바이트. 시작 전에 실제 바이트를 재서 이 값이 맞는지 먼저 확인해줘.
타일 «모양»은 이미 있다(soccer_board 의 `sb-vars--bb`). 데이터만 먹이면 그려진다 — 화면은 안 건드린다.

## 1) News.php — KBO 지표 타일 블록 삽입

`render_baseball_picks` 함수 안, 기존 MLB 타일 루프가 «끝난 바로 다음»에 새 블록을 넣는다.

아래 «현재 문장»을 찾아줘 (기존 타일 루프의 끝 + 그 다음 줄):

```php
                if ($__vars) $picks[$__i]['bb_vars'] = $__vars;
            }
        }
        $cal_dates = [];
```

변경 (가운데에 블록을 끼워 넣는다 — `$cal_dates = [];` 바로 앞):

```php
                if ($__vars) $picks[$__i]['bb_vars'] = $__vars;
            }
        }
        /* tg-step138: 야구 픽 지표 타일 — KBO/NPB 채우기.
           위 블록은 요약문이 "홈/원정 승률 N%"(MLB 형식)일 때만 돌아 KBO 카드가 빈다.
           여기서 근거 「A vs B」 항목을 타일로 꺼낸다. 값 든 것만. 숫자를 지어내지 않는다.
           매치업(=티어)은 카드 위 칩과 겹쳐 뺀다. */
        foreach ($picks as $__i => $__p) {
            if (!empty($picks[$__i]['bb_vars'])) continue;   // MLB 는 이미 채웠다
            $__kv = [];
            foreach (($__p['evidence'] ?? []) as $__e1) {
                $__n = trim((string) ($__e1['name'] ?? ''));
                $__v = trim((string) ($__e1['value'] ?? ''));
                if ($__n === '' || $__v === '' || $__n === '매치업') continue;
                if (!preg_match('/[0-9]/u', $__v)) continue;      // 숫자 없으면 막대 못 그린다
                $__parts = preg_split('/\s*vs\s*/u', $__v);
                $__pc = 50.0;
                if (count($__parts) === 2
                    && preg_match('/-?[0-9]+(?:\.[0-9]+)?/', $__parts[0], $__ma)
                    && preg_match('/-?[0-9]+(?:\.[0-9]+)?/', $__parts[1], $__mb)) {
                    $__a = abs((float) $__ma[0]);
                    $__b = abs((float) $__mb[0]);
                    if ($__n === '선발 ERA') { $__t = $__a; $__a = $__b; $__b = $__t; }  // 낮을수록 좋다 → 뒤집는다
                    $__s = $__a + $__b;
                    if ($__s > 0) $__pc = $__a / $__s * 100;
                }
                $__kv[] = ['label' => $__n, 'value' => $__v, 'pct' => round($__pc, 1)];
                if (count($__kv) >= 8) break;
            }
            if ($__kv) $picks[$__i]['bb_vars'] = $__kv;
        }
        $cal_dates = [];
```

★ **위 블록 통째로 한 번만** 삽입한다. `$cal_dates = [];` 는 원래 있던 줄이니 새로 만들지 마 —
   블록을 그 «앞»에 끼우는 거야.
★ 기존 MLB 타일 루프(`if ($__vars) ...` 로 끝나는 것)는 «건드리지 마». 그 위에 얹는 거다.
★ soccer_board.php 는 안 건드린다. `sb-vars--bb` 렌더가 이미 있어서 bb_vars 만 채우면 그려진다.
