# step223 — 분석글 1호 등록 (축구분석)

★ **tg96500 이 실서버에 반영된 «다음» 에 해줘.** 그 전에는 화면이 안 맞는다.

글 1건 등록이다. 코드 수정 없다. **파일도 안 건드린다.**

---

## 등록할 내용

```
카테고리     soccer_analysis  (축구분석 · id 16)
제목         리버풀 대 맨체스터 시티 전력 분석
             ★ 이 꼴 그대로. 앞뒤에 뭘 붙이지 마라
본문         ★ 이 문서 맨 아래 「본문 HTML」 블록 «전문 그대로»
             ★ 감싸는 <div> 나 <article> 을 «추가하지 마라». 있는 그대로 content 에 넣는다
             ★ ★ h1 이 0개다. 일부러 뺐다. 제목은 글 제목 필드가 그린다. h1 을 «만들지 마라»
created_at   ★ «지금 시각» 으로. 경기일(2026-10-12)을 넣지 마라
             픽 글은 경기일을 쓰는데 분석글은 발행 시각이다
```

## meta (JSON)

```json
{
  "league": "epl",
  "home": "리버풀",
  "away": "맨체스터 시티",
  "start_at": "2026-10-12 00:30",
  "venue": "안필드",
  "round_text": "6라운드",
  "as_of": "2026-09-30",
  "match_key": "epl-2026-10-12-liverpool-mancity"
}
```

★ `league` 가 **`epl` 소문자**여야 한다. `News::pick_league_slug()` 가 정확일치로 읽어서
글 화면에 순위표 내부링크를 붙인다. `EPL`·`프리미어리그` 로 넣으면 그게 안 붙는다.

★ `match_key` 는 나중에 «같은 경기 글을 갱신» 할 때 쓸 열쇠다. 지금은 넣어만 두면 된다.

---

## 건드리면 안 되는 것

```
News.php · header.php · category.php · Sitemap.php    ★ 이번엔 «코드 0줄» 이다
DB 카테고리 3개                                      step222 그대로 둔다

```

## 끝나면 알려줘

```
1  등록된 글 id 와 주소  /news/view/{id}
2  그 주소의 HTTP 상태 · meta robots 값   ★ 맞는 값: index, follow
3  그 주소의 h1 «개수»                  ★ 맞는 값: 1개 (제목 하나뿐)
4  본문에 <table> 이 8개, <blockquote> 가 6개 그대로 들어갔나
   (본문을 어디선가 걸러내면 표가 사라진다. 그게 제일 걱정이다)
5  /news/category/soccer_analysis 목록에 이 글이 보이나
6  meta 의 league 값이 DB 에 'epl' 로 들어갔나
```

# step225 — 분석글 감싸개에 클래스 한 개. `hp-an`

step224 잘 됐다. 실서버에서 표 8 · 인용 6 다 그려졌고 다른 글도 안 깨졌다. 확인했다.

한 가지만 덜 들어갔다. **감싸개 클래스다.**

`.content` 는 «모든 일반 기사» 의 껍데기라, 거기에 표·인용 디자인을 걸면
분석글이 아닌 기사까지 같이 바뀐다. 분석글만 걸리는 클래스가 하나 필요하다.

파일 하나야. `application/views/front/view.php`

백업 먼저.

```
cp /var/www/sportsnews/application/views/front/view.php \
   /var/www/sportsnews/application/views/front/bak225-view.php
```

## 고치는 곳 — 251행. 같은 줄이다

### 현재 문장 (251행)

```php
      <div class="content"><?= (substr($__catSlug, -9) === '_analysis') ? $sn_body : sn_render_body($sn_body) ?></div>
```

### 변경 문장

```php
      <div class="content<?= (substr($__catSlug, -9) === '_analysis') ? ' hp-an' : '' ?>"><?= (substr($__catSlug, -9) === '_analysis') ? $sn_body : sn_render_body($sn_body) ?></div>
```

바뀌는 건 «앞쪽 class 부분» 뿐이다. 뒤쪽 본문 출력 분기는 **그대로 둔다.**

```
분석글        <div class="content hp-an">   ← 띄어쓰기 «한 칸» 들어간다
그 밖의 글     <div class="content">         ← 지금과 똑같다
```

★ `content` 를 지우고 `hp-an` 으로 «바꾸는» 게 아니다. **둘 다 있어야 한다.**
기존 `.content` CSS(여백·글자 크기)가 그대로 먹어야 한다.
