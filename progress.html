# step172 — 야구 「기록」탭 라우팅 (MLB·KBO)

MLB·KBO 리그에 「기록」탭(선수 리더보드)을 붙인다. NPB 「기록」탭과 같은 구조야.
뷰 `baseball_stats.php` 는 디자인이 따로 올린다 — **그 뷰가 서버에 올라온 뒤에 이걸 반영해줘.**

두 파일이야: `News.php` 6곳 · `Sports_feed_model.php` 1곳. 파일이 다르니 한 번에 해도 돼.
★ 줄 번호는 참고용. **현재 문장으로 찾아서** 바꿔줘 (앞 배포로 밀렸을 수 있어).

base 바이트 (다르면 덮지 말고 알려줘 — 그새 남이 고친 것):
- application/controllers/News.php = 137,823
- application/models/Sports_feed_model.php = 6,617

## 백업 먼저
```
cp application/controllers/News.php application/controllers/bak-step172-News.php
cp application/models/Sports_feed_model.php application/models/bak-step172-Sports_feed_model.php
```

## News.php — 6곳

### 1) MLB 탭에 '기록' 추가 (약 1559행)
현재:
```php
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'injury' => '부상자', 'pythag' => '피타고리안', 'picks' => '픽', 'review' => '오늘의 리뷰'],
```

```php
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'leaders' => '기록', 'injury' => '부상자', 'pythag' => '피타고리안', 'picks' => '픽', 'review' => '오늘의 리뷰'],
```
