# MLB 픽 글 이틀치 확인 요청

★ **수정 지시가 아니다. 상태만 알려주면 된다.**

---

## 무엇을 확인해줬으면 하나

**8월 23일 · 24일(한국시각) MLB 픽 글이 거의 안 올라왔어.** 그날 배치가 돌았는지만 봐줘.

```
08-22 (KST)   MLB 경기 15개   →  픽 글 13건    정상
08-23 (KST)   MLB 경기 15개   →  ★ 픽 글 0건
08-24 (KST)   MLB 경기 15개   →  ★ 픽 글 1건
08-25 (KST)   MLB 경기 10개   →  픽 글 9건     정상
```

경기는 MLB 공식 일정으로 확인했어. 이틀 다 15경기가 전부 끝났어.

---

## 우리가 이미 확인한 것

같은 걸 또 보지 않게 적어둔다.

```
글이 안 보이는 게 아니다   /news/category/dailypick/2026-08-23 에 글 52건이 있다
                      그 52건이 «전부 축구» 다.  MLB 가 한 건도 없다
날짜 화면은 정상이다      2026-08-22 18건 · 08-23 52건 · 08-24 16건 · 08-25 13건
                      날짜마다 다른 글이 제대로 나온다
```

---

## 물어볼 것 세 개

```
1  08-23 · 08-24 에 MLB 픽 배치가 «돌았나»
2  돌았는데 글이 안 생겼으면 그날 로그에 뭐가 남아 있나
3  그 이틀만 안 돈 거면, 그 앞뒤(08-22 · 08-25)와 무엇이 달랐나
```

★ **고치는 건 원인을 안 다음에 하자.** 지금은 상태만 알려줘.
