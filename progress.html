# step263 — 축구분석 4차 양산 1판 (347건)

**한 건이다. 코드 0줄 · 파일 업로드 0개 · 백업 필요 없음. DB 에 새 글만 넣는다.**

```
파일   BB_분석글_축구_1차_347건.json      3,161,107바이트 · UTF-8
꼴     { "count":347, "category":"soccer_analysis", "articles":[ ... ] }
```

★ **양이 많다. 끊기면 어디까지 넣었는지 `no` 로 알려줘.** 이어서 하면 된다.

```
리그    라리가 82 · 세리에A 77 · 리그1 76 · 프리미어리그 71 · 분데스리가 41
경기일   2026-10-09 ~ 2026-12-19   (42일치)
```

★ **이게 네 판 중 1판이다.** 시즌 끝까지 1,388건인데 한 번에 던지면 끊기니까 경기일
빠른 순으로 넷으로 쪼갰다. 이 판이 끝나면 2판을 보낸다.

---

## 넣는 법

`articles` 배열 한 칸이 글 한 건이다. **루프로 돌려줘.**

```
no         1 ~ 347.  순서 그대로
title      글 제목.  ★ 이 문자열 그대로. 앞뒤에 아무것도 붙이지 마라
category   전부 "soccer_analysis"
meta       글 meta 칸에 이 json 을 그대로
content    글 본문.  ★ 이 문자열 그대로
```

```
created_at   ★ 347건 다 «지금 시각» 으로.  경기일(10-09 ~ 12-19)을 넣지 마라
본문          감싸는 <div> 나 <article> 을 «추가하지 마라»
             ★ h1 이 0개다. h1 을 «만들지 마라»
             ★ class 붙은 <div>·<table> 이 많다. 디자인이 쓰는 이름이니 지우거나 바꾸지 마라
meta         칸을 빼거나 이름을 바꾸지 마라
```

★ **로고 칸이 두 종류다. 섞지 말고 들어온 대로 넣어줘.**

```
276건   meta.home_logo_url · away_logo_url   바깥 주소 102종.  ★ 내려받아 서버에 올리지 마라
 71건   meta.home_logo · away_logo           서버에 이미 있는 파일 이름
```

★ **이미 올라간 349건과 겹치지 않는다.** 실서버 목록을 읽어서 걸렀다. 겹침 0으로 쟀다.

# step265 — 축구분석 477건 본문 교체 (경기 시각이 틀려 있다)

**새로 넣는 게 아니다. «이미 있는 글» 의 본문과 meta 를 갈아 끼운다.**
코드 0줄 · 파일 업로드 0개.

```
파일   BB_분석글_축구_시각교체_477건.json      4,359,353바이트 · UTF-8
꼴     { "count":477, "category":"soccer_analysis", "articles":[ ... ] }
```

★ **양이 많다. 끊기면 어디까지 했는지 `no` 로 알려줘.** 이어서 하면 된다.

---

## 왜 갈아 끼우나

글에 박힌 경기 시각이 **한국시간이 아니었다.** 자료가 개최지 현지 시각인데
그걸 그대로 쓰고 「한국시간」 이라고 적었다.

```
자료       2027-05-30T15:00+00:00     ← UTC
글에 박힌 것 「5월 30일(일) 15:00 한국시간」
실제 한국시간 5월 31일(월) 00:00        ← ★ 시각도 날짜도 틀렸다
```

유럽 리그 글이 전부 이렇다. 시각을 고치면 **날짜가 바뀌는 글도 있다.**

---

## 넣는 법 — ★ INSERT 가 아니라 UPDATE 다

`articles` 한 칸이 글 한 건이다. **`title` 이 같은 글을 찾아서 그 글을 고쳐줘.**

```
찾는 열쇠   category = soccer_analysis  AND  title 이 «정확히» 같은 글
갈아 끼울 것  content · meta
그대로 둘 것  글 id · created_at · 조회수 · 썸네일
```

```
★ 제목이 같은 글이 없으면  그 건은 «건너뛰고» no·title 을 알려줘.  새로 만들지 마라
★ 제목이 같은 글이 둘 이상이면  고치지 말고 no·title·id 들을 알려줘
★ title 자체는 안 바뀐다.  새 제목도 옛 제목과 같다 (팀 이름이 열쇠라서)
```

```
본문   감싸는 <div> 나 <article> 을 «추가하지 마라».  h1 은 0개다 — 만들지 마라
meta   통째로 바꾼다.  칸을 빼거나 이름을 바꾸지 마라
로고   477건 전부 로고가 들어 있다.  바깥 주소는 내려받지 말고 그대로
```

---

