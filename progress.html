# step136 — 야구 픽 탭을 날짜별 누적 + 달력으로

파일 둘이야. `News.php` 4곳, `soccer_board.php` 1곳. 화면에 달력이 새로 떠 — 화면에 영향 있는 작업이야.
이 1건만 하고 멈춰줘. 순서대로 해줘.

## 왜 하는 작업

야구 픽 탭(`/news/baseball/{리그}/picks`)이 지금은 "다가오는 경기"만 보여주고 지난 픽은 숨겨.
이걸 오늘의PICK처럼 날짜별로 나누고, 달력에서 날짜를 골라 지난 픽도 보게 바꾼다.

## 0. 백업 먼저

```
cp application/controllers/News.php application/controllers/News.php.bak136-20260820
cp application/views/front/soccer_board.php application/views/front/soccer_board.php.bak136-20260820
```

News.php base 115,057바이트 · soccer_board.php base 20,241바이트.

```php
    private function soccer_picks_merged($picks, $league) {
```
### 변경 문장
```php
    private function soccer_picks_merged($picks, $league, $include_past = false) {
```
### 왜
이 함수가 "오늘 이전 경기"를 걸러내. 야구 픽 탭은 지난 픽도 필요하니까 「과거 포함」 스위치를
단다. 기본값이 false 라 이 인자를 안 넘기는 축구 쪽 호출은 지금과 똑같이 동작해.

## 무슨 문제냐

KBO 언더오버 픽은 저장할 때 원정/홈 자리에 팀명이 아니라 '언더'·'오버' 한글이 들어가.
그런데 열쇠(pick_id)를 만들 때 영문·숫자만 남기고 지우니까, 한글이 통째로 사라져서
하루치 KBO 픽이 전부 똑같은 열쇠(`kbo___날짜`)가 돼. 그래서 서로 덮어써서 1건만 남아.

kbo_total 변환은 이미 `kbo-total-날짜-순번` 이라는 고유 열쇠를 픽마다 만들어 둬.
저장할 때 그 열쇠가 있으면 그걸 쓰게 하면 충돌이 없어져.
