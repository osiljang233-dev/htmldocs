# KBO 오늘의 리뷰 — 취소 경기 "0:0" → "취소" 표시

우천취소 경기가 화면에 "LG 0 : 0 롯데" 로 나온다. 데이터엔 이미 `status: "CANCELED"` 로 취소가 표시돼 있는데
화면이 그걸 안 보고 점수 없음을 0 으로 찍어서 그렇다. 점수 대신 "취소" 를 표시하게 고친다.

두 파일이다. 파일이 다르니 한 메시지에 같이 보내도 된다.
같은 파일 안 여러 곳은 위에서 아래 순서대로 고친다.

---

## 백업 먼저

```
cp application/views/front/kre_helpers.php application/views/front/bak-kre_helpers.php
cp application/views/front/kbo_review.php  application/views/front/bak-kbo_review.php
```

---

## 파일 1 — application/views/front/kre_helpers.php  (base 13,543바이트)

### 1곳 — 게임 배열에 취소 플래그 추가

**현재 문장** (`'homeWin' => ...` 줄)
```php
            'homeWin' => $hScore > $aScore,
```

**변경 문장** (그 줄은 그대로 두고 «바로 아래» 에 한 줄 추가)
```php
            'homeWin' => $hScore > $aScore,
            'isCancel' => in_array(strtoupper(kre_str(kre_pick($g, ['status'], 'FINAL'))), ['CANCELED','CANCELLED','CANCEL','PPD','SUSPENDED'], true),
```

---

## 파일 2 — application/views/front/kbo_review.php  (base 25,727바이트)

### 1곳 — 상단 요약 탭(경기 선택 버튼)의 점수

**현재 문장**
```php
      <button class="kre-gtab<?= $gi === 0 ? ' on' : '' ?>" data-g="<?= kre_esc($g['anchor']) ?>"><?= kre_esc($g['away']['name']) ?> <?= $hw ? '<span class="lo">'.$g['aScore'].'</span>' : '<b>'.$g['aScore'].'</b>' ?>:<?= $hw ? '<b>'.$g['hScore'].'</b>' : '<span class="lo">'.$g['hScore'].'</span>' ?> <?= kre_esc($g['home']['name']) ?></button>
```

**변경 문장**
```php
      <button class="kre-gtab<?= $gi === 0 ? ' on' : '' ?><?= !empty($g['isCancel']) ? ' cxl' : '' ?>" data-g="<?= kre_esc($g['anchor']) ?>"><?= kre_esc($g['away']['name']) ?> <?= !empty($g['isCancel']) ? '<span class="kre-cxl">취소</span>' : (($hw ? '<span class="lo">'.$g['aScore'].'</span>' : '<b>'.$g['aScore'].'</b>').':'.($hw ? '<b>'.$g['hScore'].'</b>' : '<span class="lo">'.$g['hScore'].'</span>')) ?> <?= kre_esc($g['home']['name']) ?></button>
```

### 2곳 — 카드 소제목의 점수

**현재 문장**
```php
      <span class="gt"><?= kre_esc($g['away']['name']) ?> <?= $g['aScore'] ?> : <?= $g['hScore'] ?> <?= kre_esc($g['home']['name']) ?></span>
```

**변경 문장**
```php
      <span class="gt"><?= kre_esc($g['away']['name']) ?> <?= !empty($g['isCancel']) ? '<span class="kre-cxl">취소</span>' : ($g['aScore'].' : '.$g['hScore']) ?> <?= kre_esc($g['home']['name']) ?></span>
```

### 3곳 — 큰 스코어(홈팀)

**현재 문장**
```php
        <span class="sc<?= $hw ? ' win' : ' lose' ?>" style="color:<?= $hc ?>"><?= $g['hScore'] ?><?= $hw ? '<span class="wb">WIN</span>' : '' ?></span>
```

**변경 문장**
```php
        <span class="sc<?= !empty($g['isCancel']) ? ' cxl' : ($hw ? ' win' : ' lose') ?>" style="color:<?= $hc ?>"><?= !empty($g['isCancel']) ? '–' : ($g['hScore'].($hw ? '<span class="wb">WIN</span>' : '')) ?></span>
```

### 4곳 — 큰 스코어(원정팀)

**현재 문장**
```php
        <span class="sc<?= $hw ? ' lose' : ' win' ?>" style="color:<?= $ac ?>"><?= $g['aScore'] ?><?= $hw ? '' : '<span class="wb">WIN</span>' ?></span>
```

**변경 문장**
```php
        <span class="sc<?= !empty($g['isCancel']) ? ' cxl' : ($hw ? ' lose' : ' win') ?>" style="color:<?= $ac ?>"><?= !empty($g['isCancel']) ? '–' : ($g['aScore'].($hw ? '' : '<span class="wb">WIN</span>')) ?></span>
```

### 5곳 — 상태줄(지금 "CANCELED" 영문이 그대로 나옴)

**현재 문장**
```php
      <?= $g['status'] === 'FINAL' ? '경기종료' : kre_esc($g['status']) ?>
```

**변경 문장**
```php
      <?= !empty($g['isCancel']) ? '취소' : ($g['status'] === 'FINAL' ? '경기종료' : kre_esc($g['status'])) ?>
```

## 건드리지 말 것
- 점수·WIN·이닝·타자·투수 표 등 «취소가 아닌» 경기의 표시는 그대로. `isCancel` 이 true 일 때만 바뀐다.
- `kre-cxl` · `cxl` 클래스의 CSS 는 이쪽(디자인)에서 따로 넣는다. 봇은 마크업만.

# KBO 오늘의 리뷰 — 취소 경기 뒤로 정렬 + 취소 배지 진하게

앞 판에서 취소 경기가 "취소" 로 뜨게 했다. 이번엔 두 가지.
1. 취소 경기를 뒤로 빼고, 성사된 경기를 왼쪽부터 채운다 (정렬).
2. "취소" 배지를 진하게 보이게 CSS 를 넣는다.

파일 2개다. 파일이 다르니 한 메시지에 같이 보내도 된다.

---

## 백업 먼저

```
cp application/views/front/kre_helpers.php application/views/front/bak2-kre_helpers.php
cp application/views/front/kbo_review.php  application/views/front/bak2-kbo_review.php
```

---

## 파일 1 — application/views/front/kre_helpers.php  (base 13,694바이트)

### 정렬 추가 — 성사 경기 먼저, 취소 경기는 뒤로

**현재 문장**
```php
        $out = ['date' => $date, 'games' => [], 'cancelled' => false, 'cancelReason' => ''];
        foreach ($games as $i => $g) {
            $out['games'][] = kre_game($g, $i + 1);
        }
        return $out;
```

**변경 문장** (foreach 는 그대로, `return $out;` 앞에 정렬·번호재부여 블록을 끼운다)
```php
        $out = ['date' => $date, 'games' => [], 'cancelled' => false, 'cancelReason' => ''];
        foreach ($games as $i => $g) {
            $out['games'][] = kre_game($g, $i + 1);
        }
        /* 성사 경기 먼저 · 취소 경기는 뒤로 (그룹 내 원래 순서 유지) */
        usort($out['games'], function ($a, $b) {
            $ac = !empty($a['isCancel']) ? 1 : 0;
            $bc = !empty($b['isCancel']) ? 1 : 0;
            if ($ac !== $bc) return $ac - $bc;
            return $a['idx'] - $b['idx'];
        });
        foreach ($out['games'] as $k => &$gg) { $gg['idx'] = $k + 1; }
        unset($gg);
        return $out;
```
