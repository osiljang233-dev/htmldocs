# BB 봇 지시 step207 — 야구 선수탭 제거 (News.php)

야구 «선수» 탭 3개(MLB·KBO·NPB) 없애줘.
자료 파일이 서버에 없어서 화면에 「준비중입니다」만 뜨는 빈 탭이야. 시즌도 끝나서 접는다.
`tabs` 배열에서 `'players' => '선수',` 조각만 한 줄씩 빼면 돼. 다른 건 안 건드려도 된다.

## 대상
- 파일: `/var/www/sportsnews/application/controllers/News.php`
- base 크기: **166,364 바이트**
- 고칠 곳: **3줄** (각 리그 `tabs` 배열에서 `'players' => '선수',` 만 삭제)
- 줄 번호는 실측해줘. `'players' => '선수'` 로 찾으면 딱 3군데 나와

## 0. 백업 먼저
```
cp /var/www/sportsnews/application/controllers/News.php /var/www/sportsnews/application/controllers/News.bak-step207.php
```

```
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'leaders' => '기록', 'players' => '선수', 'injury' => '부상자', 'pythag' => '피타고리안', 'picks' => '픽', 'review' => '오늘의 리뷰'],
```

- `if ($tab === 'players')` 분기(1945행 근처)랑 `render_baseball_players` 함수(2210행 근처) — 그대로 둬. 지우지 마.
