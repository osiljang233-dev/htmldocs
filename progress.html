# step139 — 파워랭킹 표 우측 공백 없애기 (soccer_board.php 한 줄)

파워랭킹 탭 순위표가 오른쪽에 큰 빈 공백을 남기고 왼쪽에 몰려 있어.
표 열 너비가 고정 px 라서 칸을 안 채우는 거야. px 를 % 로 바꾸면 표가 칸을 꽉 채워.

## 대상
```
application/views/front/soccer_board.php   (base 20,477 바이트, 102행)
```
CSS 파일·다른 탭·다른 파일은 안 건드려. 이 한 줄만.

## 먼저 백업
```
soccer_board.php 를 bak-soccer_board.php 로 복사해줘
```

## 고칠 것 — 102행 colgroup (현재 문장 전문 / 변경 문장 전문)

현재:
```
        <colgroup><col style="width:64px"><col style="width:170px"><col style="width:230px"><col style="width:230px"><col style="width:92px"><col style="width:66px"></colgroup>
```

변경:
```
        <colgroup><col style="width:8%"><col style="width:20%"><col style="width:27%"><col style="width:27%"><col style="width:10%"><col style="width:8%"></colgroup>
```

px 6개(64/170/230/230/92/66=852) → % 6개(8/20/27/27/10/8=100). 삭제 없음. 한 줄 교체만.

## 끝나면 보고
```
1  고친 파일·줄 번호
2  바뀐 뒤 그 줄 실제 코드
3  soccer_board.php 새 바이트 수
```
