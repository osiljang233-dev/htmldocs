## 배경

MLB 픽 탭 안에 「파워랭킹」「예측」「픽」 세 버튼이 있어.
파워랭킹·예측을 누르면 `/news/baseball/mlb/power`, `/news/baseball/mlb/predictions` 로 가는데 둘 다 404야.
야구에 파워랭킹·예측 자료가 없어서 탭 목록에 없고, 없는 탭은 `show_404()` 로 떨어지거든.

## 고칠 것 — 한 줄 추가

`baseball()` 메서드 안 1291행 바로 위에 한 줄 넣어줘:

**현재 (1291~1293행)**
```php
        /* tg-step109: 픽을 리그 탭에서도 본다. step38 의 301 을 푼다.
           ★ sfm 피드가 아니라 오늘의픽과 «같은 모수»(news 글)를 리그로 거른다. */
        if ($tab === 'picks') { $this->render_baseball_picks($league, $meta); return; }
```

**바꾼 뒤 (한 줄 추가)**
```php
        /* tg-step109: 픽을 리그 탭에서도 본다. step38 의 301 을 푼다.
           ★ sfm 피드가 아니라 오늘의픽과 «같은 모수»(news 글)를 리그로 거른다. */
        if (in_array($tab, ['power', 'predictions'], true)) { redirect('news/baseball/' . $league . '/picks', 'location', 301); return; }
        if ($tab === 'picks') { $this->render_baseball_picks($league, $meta); return; }
```
