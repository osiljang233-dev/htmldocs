## 2. 왜 고치나

그룹챗 블록이 홈·오늘의픽·축구 리그 순위표 6개엔 붙어 있는데 **픽 탭엔 한 개도 없어.**

이 파일 하나가 픽 탭 세 종목을 다 그려. 그래서 한 줄만 더하면 전부 붙어.

```
축구 픽   News.php soccer()                → 이 뷰
야구 픽   News.php render_baseball_picks()  → 이 뷰
농구 픽   News.php basketball()             → 이 뷰
```

블록 본체는 `application/views/front/_bbchat.php` 에 이미 있어. **새로 만들 것이 없어.**
뷰를 부르기만 하면 돼. 다른 뷰에서 이미 이렇게 쓰고 있어 (`lg_page.php` 431행).

```php
<?php $this->load->view('front/_bbchat', ['mode' => 'side']); ?>
```

## 3. 고칠 곳 — 40행 다음에 한 줄 더하기

**현재 (38~41행)**
```php
    <div class="hp-lg-head__row">
      <h1 class="hp-lg-head__h1"><?= html_escape($sbName) ?> <em><?= $sbTitle ?></em></h1>
      <span class="hp-lg-head__sub" id="sbSub"></span>
    </div>
```

**변경 후 (38~42행) — ★ 41행이 새로 들어간 줄이다**
```php
    <div class="hp-lg-head__row">
      <h1 class="hp-lg-head__h1"><?= html_escape($sbName) ?> <em><?= $sbTitle ?></em></h1>
      <span class="hp-lg-head__sub" id="sbSub"></span>
      <?php $this->load->view('front/_bbchat', ['mode' => 'strip']); ?>
    </div>
```

★ `<h1>` 줄과 `<span id="sbSub">` 줄은 **한 글자도 건드리지 마라.** 그 아래에 한 줄만 넣어.
★ `mode` 는 `'strip'` 이다. `'side'` 나 `'bare'` 로 바꾸지 마라.

# step126 — 야구 원정픽 12건 확률·지표 살리기

## 0. 먼저 백업

```
cp application/controllers/News.php application/controllers/bak2-News-step126.php
```

## 1. 대상

```
파일   application/controllers/News.php
base   113,885바이트 · 1,919줄
고칠 곳 1군데 · «두 줄 교체».  줄을 지우거나 새로 만들지 마라
```

## 2. 왜 고치나

`/news/baseball/mlb/picks` 카드 28개 중 **12개가 확률 막대와 지표 4칸이 통째로 비어 있어.**

원인은 1320행 정규식이야. `summary` 에서 **「홈 승률」이라는 말만** 찾아.

```
홈팀을 고른 픽    summary 에 「홈 승률 61%」   → 걸린다.  16건 정상
원정팀을 고른 픽   summary 에 「원정 승률 61%」  → ★ 안 걸린다.  12건이 통째로 스킵
```

실서버에서 센 것이야 — 「홈 승률」 16건 · 「원정 승률」 12건. 픽 갈래와 정확히 맞아.

`bb_vars`(지표 4칸)도 같은 `if` 안에 있어서 같이 죽어. **정규식이 두 말을 다 받게 하면 둘 다 살아나.**

★ 자료는 이미 다 와 있어. 넣을 값이 없는 게 아니야.

---

## 3. 고칠 곳 — 1320~1321행 두 줄

**현재 문장 (1320~1321행)**
```php
            if (preg_match('/홈\s*승률\s*([0-9]+(?:\.[0-9]+)?)\s*%/u', (string) ($__p['summary'] ?? ''), $__mm)) {
                $__hw = (float) $__mm[1];
```

**변경 문장**
```php
            if (preg_match('/(홈|원정)\s*승률\s*([0-9]+(?:\.[0-9]+)?)\s*%/u', (string) ($__p['summary'] ?? ''), $__mm)) {
                $__hw = ($__mm[1] === '원정') ? (100 - (float) $__mm[2]) : (float) $__mm[2];
```

바뀐 것은 둘뿐이야.

```
① 정규식에 (홈|원정) 을 넣었다.  그래서 잡는 숫자가 $__mm[1] → $__mm[2] 로 밀린다
② 「원정 승률 61%」 이면 홈 승률은 39% 다.  그래서 100 에서 뺀다
```

`$__hw` 는 **계속 «홈 승률»** 이야. 아래 코드는 한 줄도 안 고쳐도 그대로 맞아.
