# step181 — 오늘의픽 · 야구 픽탭 기본 날짜 「오늘」 고정 + 오늘 시작경기 숨김

픽 화면을 날짜 없이 열면 지금은 픽이 있는 이전 날짜로 «점프»한다.
날짜 없이 열면 항상 «오늘» 을 보여주고, 오늘 이미 시작한 경기는 숨기고,
다 숨겨져 0건이면 오늘 화면에 「없음」 메시지를 그대로 띄우게 바꿔줘.
가까운 다른 날짜로 이동하면 안 된다. 달력은 안 건드린다(과거 날짜 그대로 눌러진다).

이번엔 **같은 파일 `application/controllers/News.php` 두 곳**이야. 아래 순서대로 «현재 문장» 을 찾아서 «변경 문장» 으로 바꿔줘. 통째 덮어쓰기 금지.

### 변경 문장
```php
        /* step181 — 기본을 「오늘」 로 고정(가까운 날 점프 금지). 오늘이면 이미 시작한 경기는

        $view_date = ($date && preg_match('/^\d{4}-\d{2}-\d{2}$/', $date) && isset($__c[$date]))
            ? $date
            : $today;
        $__now = time();
        $picks = array_values(array_filter($all, function ($p) use ($view_date, $today, $__now) {
            $d = substr((string) ($p['start_at'] ?? ($p['fixture_date'] ?? '')), 0, 10);
            if ($d !== $view_date) return false;
            if ($view_date === $today) {
                $ts = !empty($p['start_at']) ? strtotime($p['start_at']) : false;
                if ($ts !== false && $ts - $__now <= 0) return false;   // 오늘 킥오프 지난 경기 숨김
```

# step182 — 오늘의픽 빈 화면 메시지를 「이유별」로

오늘의픽이 빌 때 지금은 「등록된 PICK 이 없습니다」 한 문장만 나온다.
이유에 따라 다른 문구를 띄우자 — ①오늘 경기가 있었는데 다 시작한 날 ②예정 경기가 아예 없는 날(브레이크·휴식).

파일 **두 개**야. 서로 다른 파일이라 한 번에 가도 돼. 각각 현재 문장을 찾아서 변경 문장으로 교체. 통째 덮어쓰기 금지.

## 백업 먼저
