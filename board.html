# 89단계 — 챔피언십 순위표 제목에 「EFL」이 빠져 있다

작성 2026-08-15 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 88단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

챔피언십 네 화면 중 **순위표만 「EFL」이 빠져 있어.**

```
순위표      「챔피언십 순위표 · 팀 순위 · 스포츠 뉴스」        ★ 여기만 EFL 없음
파워랭킹     「EFL 챔피언십 파워랭킹 · 스포츠 뉴스」
예측        「EFL 챔피언십 예측 · 스포츠 뉴스」
픽         「EFL 챔피언십 픽 · 스포츠 뉴스」
```

★ **왜 위험한지.** 「챔피언십」과 「챔피언스리그」는 다른 리그야.

```
챔피언십        EFL Championship — 잉글랜드 2부 리그
챔피언스리그      UEFA Champions League — 유럽 클럽 대항전
```

검색결과에 뜨는 건 `<title>` 이야. 「챔피언십」만 보이면 **챔피언스리그를 찾던 사람이 눌렀다가
2부 리그를 보고 바로 나가.** 클릭은 나는데 이탈하는 조합이라 순위에 제일 나빠.

★ 43단계에서 EFL 표기를 붙일 때 파워랭킹·예측·픽 셋만 바꾸고 순위표가 빠진 거야.

```

화면 변화        ★ h1 과 본문은 그대로.  `<title>` 과 meta description 만 바뀐다
삭제             없다
```

## 1. A건 — 야구·농구를 같이 담는다 (595~608행)

### 현재 문장 (이 15줄을 통째로 바꾼다)

```php
    /* tg-step83: DB 로 들어오는 축구 5개는 서버에 파일이 없다.
       그날 zip 안의 {리그}_standings_*.json 을 읽어서 같은 값을 구한다.
       ★ 칸 이름이 다르다 — 이쪽은 matches 다 (파일 6개는 played). 둘 다 받는다. */
    foreach (['championship', 'mls', 'primeira', 'brasileirao', 'eredivisie'] as $op_lg2) {
        $op_src = find_file($dir, $op_lg2 . '_standings_');
        if (!$op_src) continue;
        $op_j2 = json_decode(@file_get_contents($op_src), true);
        $op_p2 = 0;
        foreach ((array)($op_j2['standings'] ?? []) as $op_s2) {
            if (!is_array($op_s2)) continue;
            $op_p2 = max($op_p2, (int)($op_s2['matches'] ?? $op_s2['played'] ?? 0));
        }
        if ($op_p2 > 0) $op_season[$op_lg2] = ['played' => $op_p2];
    }
```

### 변경 문장

```php
    /* tg-step83: DB 로 들어오는 축구 5개는 서버에 파일이 없다.
       그날 zip 안의 {리그}_standings_*.json 을 읽어서 같은 값을 구한다.
       ★ 칸 이름이 다르다 — 이쪽은 matches 다 (파일 6개는 played). 둘 다 받는다. */
    /* tg-step84: 야구·농구도 같은 자리에서 담는다. 표 생김새가 셋이라 훑는 법을 바꿨다.
       ★ 평평하지 않다 — MLB 는 지구별, WNBA 는 컨퍼런스별, NPB 는 센트럴/퍼시픽으로
         한 겹 더 싸여 있다. 그래서 standings 배열만 도는 방식으로는 0 이 나온다.
       ★ 칸 이름도 리그마다 다르다 — matches · games · played 중 하나이고,
         NPB 는 숫자 칸이 없이 rec: {w, l} 로 온다. 넷 다 받는다.
       ★ 아무 곳의 games 나 집으면 안 된다. 팀 한 줄로 보이는 칸(team·rank 등)이
         같이 있는 자리에서만 읽는다. 그래야 meta 의 총 경기 수 같은 걸 안 집는다. */
    $op_dig = function ($op_node) use (&$op_dig) {
        if (!is_array($op_node)) return 0;
        $op_best = 0;
        $op_isteam = false;
        foreach (['team', 'team_ko', 'team_abbr', 'name', 'short', 'rank'] as $op_tk) {
            if (isset($op_node[$op_tk])) { $op_isteam = true; break; }
        }
        if ($op_isteam) {
            foreach (['matches', 'games', 'played'] as $op_gk) {
                if (isset($op_node[$op_gk]) && is_numeric($op_node[$op_gk])) {
                    $op_best = max($op_best, (int)$op_node[$op_gk]);
                }
            }
            if (isset($op_node['rec']) && is_array($op_node['rec'])) {
                $op_rec = $op_node['rec'];
                $op_best = max($op_best, (int)($op_rec['w'] ?? 0) + (int)($op_rec['l'] ?? 0)
                                       + (int)($op_rec['t'] ?? ($op_rec['d'] ?? 0)));
            }
        }
        foreach ($op_node as $op_child) {
            if (is_array($op_child)) $op_best = max($op_best, $op_dig($op_child));
        }
        return $op_best;
    };
    foreach (['championship', 'mls', 'primeira', 'brasileirao', 'eredivisie',
              'mlb', 'kbo', 'npb', 'nba', 'wnba', 'kbl', 'wkbl'] as $op_lg2) {
        $op_src = find_file($dir, $op_lg2 . '_standings_');
        if (!$op_src) continue;
        $op_j2 = json_decode(@file_get_contents($op_src), true);
        $op_p2 = $op_dig($op_j2);
        if ($op_p2 > 0) $op_season[$op_lg2] = ['played' => $op_p2];
    }
```

★ **비시즌 리그는 따로 막지 않아도 돼.** NBA·KBL·WKBL 은 지금 자료가 0행이라
`$op_p2` 가 0 으로 나오고 `if ($op_p2 > 0)` 에서 저절로 빠져. 10월에 자료가 들어오면 저절로 켜져.
