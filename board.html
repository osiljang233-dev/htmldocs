# 92단계 — 글 제목에 경기 날짜 붙이기

파일 하나다. `application/controllers/News.php`

```
base   85,938 바이트 · 1,551줄        ← 시작 전에 이 값이 맞는지 봐줘. 다르면 멈추고 알려줘
```

---

## 1. 백업 먼저

```bash
cp /var/www/sportsnews/application/controllers/News.php \
   /var/www/sportsnews/application/controllers/bak5-News.php
```

## 2. 왜 고치나

`/news/view/{id}` 130건 중 **85건의 `<title>` 이 글자까지 같다.** 37묶음이야.

```
/news/view/700 · 719 · 735 · 743
  전부   보스턴 레드삭스 @ 토론토 블루제이스 — 보스턴 레드삭스 승 · 스포츠뉴스
```

같은 두 팀이 며칠 뒤 다시 붙으면 제목이 그대로 재사용돼. 제목에 날짜가 없어서야.

경기 날짜는 **이미 DB 에 있다.** `meta` 컬럼 안의 `start_at` 이고,
`application/views/front/view.php` 39행·80행이 이미 그 값으로 「경기 2026.08.10 08:10」 을 찍고 있어.
**같은 값을 제목에도 쓰는 것뿐이야. 새 자료는 필요 없어.**

## 3. 무엇을 고치나

`News::view()` 안이다. **505행은 그대로 두고, 506행 `];` 다음에 새 줄을 넣는다.**

### 현재 (504~508행)

```php
            'comment_count' => $this->cmm->count_for('news', $id),
            'title'      => $item->title . ' · 스포츠뉴스',
        ];

        // tg78085 — article meta description from body lead (first ~150 chars)
```

### 변경 후

```php
            'comment_count' => $this->cmm->count_for('news', $id),
            'title'      => $item->title . ' · 스포츠뉴스',
        ];

        /* tg-step92: 제목에 «경기 날짜» 를 붙인다.  같은 대진이 며칠 뒤 다시 붙으면
           title 이 글자까지 같아져서, 색인된 글 130건 중 85건이 중복이었다.
           값은 meta.start_at 이고 view.php 39·80행이 이미 같은 값을 쓴다 — 화면과 안 어긋난다.
           start_at 이 없는 글은 이 if 가 안 걸려서 옛 제목 그대로다. */
        $__m92 = json_decode((string)($item->meta ?? ''), true);
        $__ts92 = (is_array($__m92) && !empty($__m92['start_at'])) ? strtotime($__m92['start_at']) : false;
        if ($__ts92) {
            $data['title'] = $item->title . ' (' . date('Y.m.d', $__ts92) . ') · 스포츠뉴스';
        }

        // tg78085 — article meta description from body lead (first ~150 chars)
```

**넣는 것은 위의 9줄(주석 4줄 + 코드 5줄)뿐이다.** 지우는 줄은 없다.

## 4. 건드리지 마

```
505행 자체            그대로 둔다.  start_at 이 없는 글의 기본값이다
description 만드는 블록  508~524행.  손대지 마
is_indexable · robots  526행 아래.  손대지 마
view.php · header.php  이번엔 안 건드린다
application/config/    절대 안 된다
```

`<h1>` 도 이번엔 안 바꾼다. 본문에 이미 경기 날짜가 찍혀 있어서 h1 에 또 넣으면 겹쳐.

## 5. 반영 전에

```bash
php -l /var/www/sportsnews/application/controllers/News.php
```

통과 안 하면 올리지 말고 알려줘.

## 6. 끝나면 알려줄 것

```
1  News.php 크기        85,938  →  얼마가 됐나
2  넣은 자리            몇 행부터 몇 행까지
3  실제 코드            넣은 9줄을 그대로 붙여줘
4  php -l 결과
5  화면 확인 — 아래 세 주소의 <title> 을 그대로 적어줘
     /news/view/700
     /news/view/719
     ★ /news/view/28      ← 이건 픽이 아니라 start_at 이 없다.  «안 바뀌어야» 정상이다
```

★ 700 과 719 의 title 이 **서로 달라야** 성공이다. 28 은 그대로여야 하고.

## 7. 되돌리는 법

```bash

   /var/www/sportsnews/application/controllers/News.php
```

# 93단계 — h1 에 경기 날짜 올리기 · 밑줄은 시각만

파일 하나다. `application/views/front/view.php`

```
base   13,951 바이트 · 274줄        ← 시작 전에 이 값이 맞는지 봐줘. 다르면 멈추고 알려줘
```

고치는 줄은 **두 줄**이다. 73행과 80행. 넣거나 지우는 줄은 없다.

---

## 1. 백업 먼저

```bash
cp /var/www/sportsnews/application/views/front/view.php \
   /var/www/sportsnews/application/views/front/bak-step93-view.php
```

## 2. 무엇을 바꾸나

지금 픽 글 화면이 이렇다.

```
보스턴 레드삭스 @ 토론토 블루제이스 — 보스턴 레드삭스 승
2026.08.11 09:00 · 경기 2026.08.12 08:07 · 조회 12
```

제목에 날짜가 없어서 **다른 날 경기인데 제목이 글자까지 같다.** 날짜를 제목으로 올린다.

```
보스턴 레드삭스 @ 토론토 블루제이스 — 보스턴 레드삭스 승 (2026.08.12)
2026.08.11 09:00 · 경기 08:07 · 조회 12
```

**날짜가 사라지는 게 아니라 위로 올라가는 것이다.** 화면에서 없어지는 정보는 없다.

## 3. 고칠 것 ① — 73행 h1

### 현재 (73행 한 줄)

```php
      <h1 class="hp-ahero__title"><?= html_escape($item->title) ?></h1>
```

### 변경 후 (73행 한 줄)

```php
      <h1 class="hp-ahero__title"><?= html_escape($item->title) ?><?php if ($__start_ts): ?> (<?= date('Y.m.d', $__start_ts) ?>)<?php endif; ?></h1>
```

`$__start_ts` 는 39행에서 이미 만들어져 있다. 새로 만들지 마.

## 4. 고칠 것 ② — 80행 경기 시각

### 현재 (80행 한 줄)

```php
        <?php if ($__start_ts): ?><span>· 경기 <?= date('Y.m.d H:i', $__start_ts) ?></span><?php endif; ?>
```

### 변경 후 (80행 한 줄)

```php
        <?php if ($__start_ts): ?><span>· 경기 <?= date('H:i', $__start_ts) ?></span><?php endif; ?>
```

`Y.m.d ` 만 빠진다. `H:i` 는 그대로다.

## 5. 건드리지 마

```
201행 h1        <h1><?= html_escape($item->title) ?></h1>   ← 일반 글용이다.  그대로 둬
76행            발행일 <?= date('Y.m.d H:i', strtotime($item->created_at)) ?>   그대로 둬
39행            $__start_ts 만드는 줄.  그대로 둬
85행 아래         hp-strip 전부.  손대지 마
News.php · header.php · assets/*      이번엔 안 건드린다
application/config/                   절대 안 된다
```

## 6. 반영 전에

```bash
php -l /var/www/sportsnews/application/views/front/view.php
```

통과 안 하면 올리지 말고 알려줘.

## 7. 끝나면 알려줄 것

```
1  view.php 크기       13,951  →  얼마가 됐나
```
