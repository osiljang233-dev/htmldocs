# 83단계 — 개막 요약 파일에 「시즌 중」 리그를 같이 담는다

작성 2026-08-16 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 82단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

`_openers.json` 은 지금 **개막 «전»** 리그만 담아. 그래서 시즌 중인 리그는 머리에 표시할 게 없어.

```
지금      epl · laliga · bundesliga · ligue1 · seriea    개막 D- 배지가 붙는다
없는 것    kleague1 · championship · mls · primeira · brasileirao · eredivisie
         ★ 시즌 중이라 82단계가 뺐다.  뺀 건 맞는데 「시즌 중」이라는 표시가 없다
```

★ **머리가 리그 순위표를 직접 읽을 수는 없어.** 드롭다운은 모든 페이지에 뜨거든.
그래서 이 파일에 `season` 을 같이 담는 거야.

```json
{ "generated_at": "…",
  "openers": { "epl": "2026-08-21T20:00:00+01:00", … },
  "season":  { "kleague1": {"played": 22}, "mls": {"played": 18}, … } }
```

★ **화면은 우리가 안 건드려.** 머리 쪽은 이미 이 값을 읽게 돼 있어 (tg84980).
**이 파일에 `season` 이 생기면 배포 없이 저절로 켜져.**

```
파일 1개 · 3곳   scripts/import-snapshot-flex.php
```

### 변경 문장 — 위 9줄을 아래 전부로 바꿔줘

```php
    /* tg-step83: DB 로 들어오는 축구 5개는 서버에 파일이 없다.
       그날 zip 안의 {리그}_standings_*.json 을 읽어서 같은 값을 구한다.
       ★ 칸 이름이 다르다 — 이쪽은 matches 다 (파일 6개는 played). 둘 다 받는다. */
    foreach (['championship', 'mls', 'primeira', 'brasileirao', 'eredivisie'] as $op_lg2) {
        $op_src = find_file($dir, $op_lg2 . '_standings_');
        if (!$op_src) continue;
        $op_j2 = json_decode(@file_get_contents($op_src), true);
        $op_p2 = 0;
        foreach ((array)($op_j2['standings'] ?? []) as $op_s2) {
            if (!is_array($op_s2)) continue;
            $op_p2 = max($op_p2, (int)($op_s2['matches'] ?? $op_s2['played'] ?? 0));
        }
        if ($op_p2 > 0) $op_season[$op_lg2] = ['played' => $op_p2];

    /* 한 리그도 못 구했으면 「쓰지 않는다」. 빈 파일로 덮으면 배지가 통째로 사라진다. */
    if (!$op_out) throw new RuntimeException('구한 리그가 0개다');

    /* tg-step83: ★ 덮어쓰지 않고 「합친다」.
       DB 5개는 그날 zip 에 그 리그가 안 오면 값을 못 구한다.
       그냥 쓰면 season 에서 빠지고 화면의 ON 표시가 하루 사라졌다 다시 켜진다.

    $op_prev = [];
    $op_old = @file_get_contents($op_dir . '/_openers.json');

    ksort($op_season);

    $op_body = json_encode(

        JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_PRETTY_PRINT

    if (!$op_body) throw new RuntimeException('json_encode 실패');
```

## 주의할 점

- **`+=` 를 `max()` 로 바꾸는 게 A건의 핵심이야.** 판정은 같지만 값이 달라져. 되돌리지 말아줘
- **`$op_season = $op_season + $op_prev;` 의 순서를 바꾸지 말아줘.** PHP 의 `+` 는 «왼쪽» 키를 남겨.
  뒤집으면 옛 값이 오늘 값을 덮어써서 영원히 안 갱신돼
- **`array_merge` 를 쓰지 말아줘.** 문자열 키에서 동작이 달라
- **C건의 칸 이름이 `matches` 야.** 파일 6개(`played`)와 다르니 둘 다 받는 그 줄을 줄이지 말아줘
- **`find_file` 은 이미 있는 함수야** (52행 근처). 새로 만들지 말아줘
- `$dir` 는 이 스크립트가 인자로 받은 unzip 폴더야. **새로 정하지 말아줘**
- **80·81·82단계 블록을 건드리지 말아줘.** 특히 `$kl_` 로 시작하는 부분
- 변수 이름이 `$op_season` · `$op_lg2` · `$op_j2` · `$op_s2` · `$op_p2` · `$op_prev` · `$op_old` · `$op_oldj` 야.
  **앞 단계 변수와 안 겹치게 한 거니 바꾸지 말아줘**
- 들여쓰기는 A·B건이 스페이스 8칸, C·D건이 4칸

```php
        }
        return $op_best;
```
