# MLB 오늘의 리뷰 라우트 — News.php 4곳

`/news/baseball/mlb/review` 를 열어주는 작업이야. KBO 리뷰랑 똑같은 구조로 MLB만 추가해.
**한 파일(`News.php`) 안에서 4곳**을 고친다. 문자열로 찾아서 바꿔줘. 줄 번호는 참고만.

## ★ 보내기 전 조건 (봇이 볼 건 아님)
> front/mlb_review.php 뷰 파일이 서버에 이미 올라가 있어야 한다. 4번(뷰 분기)이 뷰 없이 들어가면 500.

## 대상 파일

```
application/controllers/News.php    base 120,947 바이트
```

## 먼저 백업

```
cp application/controllers/News.php application/controllers/bak-News-mlbreview.php
```

---

## ① MLB 탭 목록에 review 추가 (1303행 부근)

```
현재 문장
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'injury' => '부상자', 'pythag' => '피타고리안', 'picks' => '픽'],

변경 문장
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'injury' => '부상자', 'pythag' => '피타고리안', 'picks' => '픽', 'review' => '오늘의 리뷰'],
```

※ 이건 `'mlb' =>` 블록 안의 tabs 야. `'kbo' =>` 블록의 tabs(이미 review 있음)는 건드리지 마.

---

## ② kind 매핑 동적화 (1357행 부근) — ★ 제일 중요

지금은 리그와 무관하게 무조건 `kbo_review` 라, 이 줄 안 고치면 MLB 탭에 KBO 데이터가 뜬다.

```
현재 문장
            'review' => 'kbo_review',

변경 문장
            'review' => $league . '_review',
```

---

## ③ 보드 라벨에 mlb_review 추가 (1874행 부근)

`$board_labels` 배열에서 `'kbo_review' => 'KBO 오늘의 리뷰',` 를 찾아 그 «바로 뒤»에 MLB 항목을 붙여.

```
현재 문장
'kbo_starter_eval' => 'KBO 선발 평가', 'kbo_review' => 'KBO 오늘의 리뷰', 'soccer_absences' => '해외축구 결장자 명단',

변경 문장
'kbo_starter_eval' => 'KBO 선발 평가', 'kbo_review' => 'KBO 오늘의 리뷰', 'mlb_review' => 'MLB 오늘의 리뷰', 'soccer_absences' => '해외축구 결장자 명단',
```

---

## ④ 뷰 분기 추가 (1648행 부근) — ★ 뷰 파일 있을 때만

`kbo_review` 뷰 분기 바로 아래에 `mlb_review` 분기 한 줄을 붙여.

```
현재 문장
        if ($kind === 'kbo_review') { $this->layout('front/kbo_review', $data); return; }

변경 문장
        if ($kind === 'kbo_review') { $this->layout('front/kbo_review', $data); return; }
        if ($kind === 'mlb_review') { $this->layout('front/mlb_review', $data); return; }
```

---

## 안 건드리는 것
- `Sitemap.php` — 자동 조립이라 손 안 대. (②만 고치면 `mlb_review` 자동 인식)
- `sport_league_head.php` `$__kickMap` — `review => REVIEW` 이미 있음.
- `is_indexable()` — 리뷰 보드는 자체 게이트(payload 0건이면 noindex) 씀. 손 안 대.
- `'kbo' =>` 블록, 다른 kind, 다른 리그 — 다 그대로.

## 끝나면 알려줘
1. 고친 4곳 각각 실제 바뀐 줄
2. `curl -s https://www.버저비터.com/news/baseball/mlb/review` 가 200 인지, 화면에 MLB 리뷰가 뜨는지 (KBO 아니라 MLB 데이터인지)
3. `curl -s https://www.버저비터.com/news/baseball/kbo/review` 도 여전히 KBO 로 정상인지 (②동적화가 KBO 안 깼는지)
