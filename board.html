# 아침 배치에서 «반영 안 된 14개» 가 뭔지 알려줘

★ **수정 지시가 아니다. 상태만 알려주면 된다.**

---

## 물어볼 것

오늘(2026-08-26) 아침 배치 보고가 이랬어.

```
파일 67개 중 53건 성공 · 실패 0건
```

**그럼 나머지 14개는 뭐야?** 실패도 아닌데 성공에도 안 들어갔잖아.

```
1  ★ 반영 안 된 14개 파일 «이름» 을 알려줘
2  각각 왜 건너뛰었나  (자료가 없어서 · 형식이 안 맞아서 · 대상 경로가 없어서 …)
3  ★ 그중에 kleague1 이 있나
```

---

## 우리가 이미 확인한 것

같은 걸 또 보지 않게 적어둔다.

```
epl.json       2026-08-25 22:03 로 갱신됨   정상
laliga.json    2026-08-25 22:03 로 갱신됨   정상
kleague1.json  ★ 2026-08-24 06:31 그대로   이틀째 안 바뀐다
```

★ **고치는 건 원인을 안 다음에 하자. 지금은 상태만 알려줘.**

# ★ 수정 지시다

## 백업 먼저
아래 5개 파일 손대기 전에 각각 `bak-` 붙여서 복사해둬.
`/var/www/sportsnews/assets/data/eredivisie.json` → `bak-eredivisie.json`
`/var/www/sportsnews/assets/data/mls.json` → `bak-mls.json`
`/var/www/sportsnews/assets/data/primeira.json` → `bak-primeira.json`
`/var/www/sportsnews/assets/data/brasileirao.json` → `bak-brasileirao.json`
`/var/www/sportsnews/assets/data/championship.json` → `bak-championship.json`
(파일이 아예 없으면 백업 생략하고 새로 만들면 돼)

## 지금 상태 (실서버 실측, 2026-08-26)

아침 묶음에 매일 들어오는 경기결과 9개 파일 중 5개가 서버에 못 들어가고 있어.

| 리그 | assets/data 파일 | HTTP |
|---|---|---|
| 네덜란드 에레디비지 | eredivisie.json | 404 |
| MLS | mls.json | 404 |
| 포르투갈 프리메이라 | primeira.json | 404 |
| 브라질 브라질레이랑 | brasileirao.json | 404 |
| 잉글랜드 챔피언십 | championship.json | 404 |

나머지 4개(EPL·라리가·리그1·세리에A)는 이미 파일이 있고 정상 작동 중이야. 이 4개를 형식 본보기로 써.

## 본보기 파일 (이미 되는 것)

`/var/www/sportsnews/assets/data/laliga.json` — HTTP 200, 64,625바이트, `results` 배열에 17건.
`results` 배열의 한 항목 구조:

```json
{"home": "VAL", "away": "BET", "home_score": 0, "away_score": 1, "kickoff": "2026-08-25T00:00:00+09:00", "kickoff_text": "2026-08-25", "venue": null}
```

이 구조 그대로, 위 5개 리그도 같은 자리(`/var/www/sportsnews/assets/data/{리그}.json`)에 `results` 배열을 채워줘.

★ 한 번 채우고 끝이 아니야. **아침 배치 임포터에 이 5개 리그 경기결과를 넣는 칸을 만들어서, 앞으로 매일 자동으로 들어가게** 해줘. 오늘 「건너뛴 14개」 중 경기결과 9개가 바로 이거야 — 그중 5개가 갈 곳이 없는 상태다.

## 참고 — bundesliga 는 다른 문제

`/var/www/sportsnews/assets/data/bundesliga.json` 은 HTTP 200 (60,303바이트) 인데 `results` 배열이 0건이야. 파일 자리는 있는데 안이 안 채워지는 케이스라 이번 5개랑 원인이 다를 수 있어. 이것도 같이 봐줘.

## 수정 후 보고할 것

1. 수정한 파일 목록 (경로 전체)
2. 각 파일의 서버 절대 경로
3. 이번에 처리한 리그 이름 5개 (eredivisie·mls·primeira·brasileirao·championship)
4. 오늘 아침 zip 으로 시험 반입한 결과 (성공/실패, 몇 건 들어갔는지)
5. 각 파일 최종 크기(바이트)
