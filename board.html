# step233 — 분석글 1715·1716 「대한민국」 → 「한국」 (제목·meta·본문)

★ **tg97400 이 실서버에 반영된 «다음» 에 해줘.**

**코드 0줄 · 파일 0개.** 글 두 건의 «제목 · meta.home · content» 를 바꾼다.

## 왜

검색어를 실측했더니 우리 제목이 검색에 안 걸리는 말로 돼 있었다.

```
전력 분석            검색 수요 0
축구분석             1,000 (난이도 0)
한국 대 우즈베키스탄    1,100
한국 베네수엘라        20   ·  대한민국 베네수엘라  10
```

「대한민국」 을 「한국」 으로, 「전력 분석」 을 「축구 분석」 으로 바꾼다.

```

제목 (후)   한국 대 베네수엘라 축구 분석
```

meta 에서 **`home` 한 칸만** 바꾼다. 나머지는 그대로 둔다.

home (전)   대한민국
home (후)   한국
```

`content` 는 맨 아래 「1715 본문」 블록으로 통째 교체. **8,951 → 8,855바이트**

## ★ 제목과 meta.home 이 «짝» 이어야 한다

`view.php` 가 제목을 팀 단위로 쪼갤 때 `meta.home + ' 대 ' + meta.away` 가
**제목 맨 앞과 정확히 같아야** 한다. 하나만 바꾸면 h1 이 통짜로 나온다.

```
맞는 짝   제목 「한국 대 베네수엘라 축구 분석」 · home 「한국」 · away 「베네수엘라」
         → prefix 「한국 대 베네수엘라」 가 제목 앞과 일치 · 꼬리 「축구 분석」
```

★ `created_at` 도 **안 바꾼다.**
