# step124 — 픽 탭 제목 라인에 그룹챗 블록 넣기

## 0. 먼저 백업

```
cp application/views/front/soccer_board.php application/views/front/bak-soccer_board-step124.php
```

## 1. 대상

```
파일   application/views/front/soccer_board.php
base   19,309바이트 · 335줄
고칠 곳 1군데.  ★ «한 줄을 더한다».  기존 줄을 지우거나 고치지 마라
```

## 2. 왜 고치나

그룹챗 블록이 홈·오늘의픽·축구 리그 순위표 6개엔 붙어 있는데 **픽 탭엔 한 개도 없어.**

이 파일 하나가 픽 탭 세 종목을 다 그려. 그래서 한 줄만 더하면 전부 붙어.

```
축구 픽   News.php soccer()                → 이 뷰
야구 픽   News.php render_baseball_picks()  → 이 뷰
농구 픽   News.php basketball()             → 이 뷰
```

블록 본체는 `application/views/front/_bbchat.php` 에 이미 있어. **새로 만들 것이 없어.**
뷰를 부르기만 하면 돼. 다른 뷰에서 이미 이렇게 쓰고 있어 (`lg_page.php` 431행).

```php
<?php $this->load->view('front/_bbchat', ['mode' => 'side']); ?>
```

---

## 3. 고칠 곳 — 40행 다음에 한 줄 더하기

**현재 (38~41행)**
```php
    <div class="hp-lg-head__row">
      <h1 class="hp-lg-head__h1"><?= html_escape($sbName) ?> <em><?= $sbTitle ?></em></h1>
      <span class="hp-lg-head__sub" id="sbSub"></span>
    </div>
```

**변경 후 (38~42행) — ★ 41행이 새로 들어간 줄이다**
```php
    <div class="hp-lg-head__row">
      <h1 class="hp-lg-head__h1"><?= html_escape($sbName) ?> <em><?= $sbTitle ?></em></h1>
      <span class="hp-lg-head__sub" id="sbSub"></span>
      <?php $this->load->view('front/_bbchat', ['mode' => 'strip']); ?>
    </div>
```

★ `<h1>` 줄과 `<span id="sbSub">` 줄은 **한 글자도 건드리지 마라.** 그 아래에 한 줄만 넣어.
★ `mode` 는 `'strip'` 이다. `'side'` 나 `'bare'` 로 바꾸지 마라.

---

## 4. 건드리면 안 되는 것

```

_bbchat.php                   블록 본체.  열지 마라
42행 hp-lg-head__rule          그대로
76 · 179 · 232행 <script>       sbSub 에 글자를 넣는 코드.  그대로
News.php                      이번엔 안 고친다
```

```

```

# 데이터 요청 — 규격서 + 검사기 (2026-08-17)

봇이 보내는 JSON 규격을 문서로 못박았어. 같이 **검사기**도 넣었으니 봇이 보내기 전에
스스로 돌려서 통과한 것만 보내주면 돼. 그러면 우리가 매번 열어볼 일이 없어진다.

## 같이 보내는 것 3개

```
1_읽어주세요.md    이 글
2_데이터규격서.md   ★ 봇이 읽을 규격. 1장=탭별 필드 · 2장=리그·탭 목록
검사.bat           ★ 이것만 부르면 된다
validate.py        검사기 본체
spec.json          규격 원본 (셋을 같은 폴더에 두면 그대로 돈다)
```

## 봇이 할 것

```
검사.bat 보낼파일.json
```

★ **종류를 안 알려줘도 된다.** 파일 안을 보고 알아서 고른다.
★ 그냥 `검사.bat` 만 눌러도 된다. 그 폴더의 `.json` 을 전부 검사한다.
★ **봇에 붙일 때는 종료코드만 보면 된다** — `0` 이면 보내고, `1` 이면 안 보낸다.

통과하면 종료코드 0. 실패하면 **무엇이 어떻게 틀렸는지 · 어떻게 고치는지**까지 찍어준다.
예 — 「46.7 은 퍼센트로 보인다. 0.467 로 보내라」

```
python validate.py --list                 검사할 수 있는 종류 목록 (24가지)
python validate.py --sample soccer_picks  통과하는 예시 파일을 찍어준다
```

```
① 필드 이름을 바꾸지 마라        「선발 ERA」를 「선발평균자책」으로 바꾸면 화면이 빈다
② 못 채우면 null 로 두고         항목 자체는 남겨라. 통째로 빼지 마라
   ★ 그리고 담당자에게 보고해라   말없이 넘기면 아무도 모른다. 화면만 0 으로 뜬다
③ 값 형식을 지켜라              "2.41 vs 5.52" 는 ★ 원정 vs 홈 순서다
```
