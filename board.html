# 95단계 — 글 화면도 `kickoff_time` 을 먼저 본다 (한 줄)

파일 한 장, 고치는 줄 **하나**야. `application/views/front/view.php`

```
base   14,022바이트 · 275줄        ← 시작 전에 맞는지 봐줘. 다르면 멈추고 알려줘
```

---

## 1. 백업 먼저

```bash
cp /var/www/sportsnews/application/views/front/view.php \
   /var/www/sportsnews/application/views/front/bak-step95-view.php
```

## 2. 왜 고치나

같은 경기인데 화면마다 시각이 다르게 나온다.

```
경기          실제(MLB 공식)     홈 오늘의픽    /news/view/{id}
BOS @ PIT    08-17 02:35       ★ 02:35      08:15   ✗
BAL @ TB     08-17 01:15       ★ 01:15      07:10   ✗
```

**홈은 맞는 값을 보여준다.** 읽는 키가 달라서다.

```
News.php 85행 · 127행   $kick = $meta['kickoff_time'] ?? ($meta['start_at'] ?? null);
                       ← 「kickoff_time 별칭 허용 — 정본은 start_at」 주석이 붙어 있다
view.php 39행           $__meta['start_at'] 만 본다.  ★ 별칭 허용이 없다
```

`view.php` 에도 같은 별칭 허용을 넣는다. **News.php 를 그대로 따라가는 것이고 새 규칙이 아니다.**

## 3. 고칠 것 — 39행 한 줄

### 현재 (39행)

```php
  $__start_ts = !empty($__meta['start_at']) ? strtotime($__meta['start_at']) : false;
```

### 변경 후 (39행)

```php
  /* tg-step95: kickoff_time 별칭을 먼저 본다. News.php 85·127행과 같은 규칙이다.
     이 줄이 start_at 만 보던 탓에 홈은 02:35, 글은 08:15 로 갈렸다. */
  $__k95 = $__meta['kickoff_time'] ?? ($__meta['start_at'] ?? null);
  $__start_ts = !empty($__k95) ? strtotime((string)$__k95) : false;
```

**한 줄을 네 줄(주석 2 + 코드 2)로 바꾼다.** 다른 줄은 손대지 마.

## 4. 건드리지 마

```
73행 h1 · 80행 「· 경기 HH:MM」   ★ 그대로 둔다.  값만 맞으면 화면은 저절로 맞는다
76행 발행일 date('Y.m.d H:i', strtotime($item->created_at))   손대지 마
News.php · header.php · Sitemap.php    이번엔 안 건드린다
application/config/                    절대 안 된다
```

## 5. 반영 전에

```bash
php -l /var/www/sportsnews/application/views/front/view.php
```

통과 안 하면 올리지 말고 알려줘.

## 6. 끝나면 알려줄 것

```
1  view.php 크기     14,022 → 얼마
2  39행 자리         몇 행부터 몇 행까지
3  넣은 코드 4줄      그대로 붙여줘
4  php -l 결과
5  화면 확인 — 아래 두 글의 «h1» 과 «그 밑줄» 을 그대로 적어줘
     /news/view/769      (보스턴 레드삭스 @ 피츠버그 파이리츠)
     /news/view/770      (볼티모어 오리올스 @ 탬파베이 레이스)
   ★ 769 밑줄이 「· 경기 02:35」 · 770 이 「· 경기 01:15」 여야 성공이다
6  ★ /news/view/28  — start_at 도 kickoff_time 도 없는 글이야.  «아무것도 안 바뀌어야» 정상
```

★ h1 끝의 날짜 `(2026.08.17)` 도 이 값에서 나온다. 시각이 바뀌면 날짜가 하루 당겨질 수 있어.
**그것도 같이 적어줘.**

## 7. 되돌리는 법

```bash
cp /var/www/sportsnews/application/views/front/bak-step95-view.php \
   /var/www/sportsnews/application/views/front/view.php
```

# 96단계 — 순위 화면 본문에 찍히는 빨간 PHP 에러 박스 없애기

파일 2개다. 서로 안 겹치니까 한 번에 해줘.

```
① application/views/front/_helpers.php    base 8,681바이트 · 188줄
② application/views/front/lg_page.php     base 38,100바이트 · 680줄
```

---

## 0. 백업 먼저

```
cp application/views/front/_helpers.php  application/views/front/bak96-_helpers.php
cp application/views/front/lg_page.php   application/views/front/bak96-lg_page.php
```

---

## 1. 지금 어떤 상태인가

실서버 본문에 빨간 테두리 에러 박스가 그대로 찍혀 있어.

```
/news/soccer/kleague1/standings    에러 박스 262개   ← 페이지가 630KB 다
/news/soccer/laliga/standings      에러 박스   4개
Undefined index: round  —  front/_helpers.php 138행 · front/lg_page.php 469행
```

`assets/data/laliga.json` · `kleague1.json` 의 `results` 항목에 `round` 키가 없어.
`fixtures` 에는 다 있고 `results` 에만 없다.

```
laliga     results   2건  전부 round 없음      fixtures 120건  전부 있음
kleague1   results 131건  전부 round 없음      fixtures  78건  전부 있음
```

그래서 `sn_kl_group_by_round` 가 첫 그룹을 못 만들고 `$groups[-1]` 로 떨어져.
그 뒤로 경기 1건마다 그룹이 하나씩 생겨서 K리그1 결과 탭이
「제목 빈칸 + 1경기」 블록 131개로 그려져 있다. 131 + 131 = 262 다.

**자료를 고치는 게 아니라 코드가 안 죽게 만드는 거야. 경기는 하나도 안 버린다.**

---

## 2. `_helpers.php` — 133~145행

### 현재 문장

```php
    function sn_kl_group_by_round($items, $max_rounds) {
        $groups = [];
        $round_count = 0;
        $last_round = null;
        foreach ($items as $m) {
            if ($m['round'] !== $last_round) {
                if ($round_count >= $max_rounds) break;
                $round_count++;
                $last_round = $m['round'];
                $groups[] = ['round' => $m['round'], 'matches' => []];
            }
            $groups[count($groups) - 1]['matches'][] = $m;
        }
```

### 변경 문장

```php
    function sn_kl_group_by_round($items, $max_rounds) {
        $groups = [];
        $round_count = 0;
        $last_key96 = null;
        // tg-step96: results 에는 round 키가 아예 없다. 그대로 읽으면 Notice 가 본문에 찍히고,
        // 첫 그룹이 안 만들어져서 $groups[-1] 로 떨어져 경기 1건마다 그룹이 생긴다.
        // round 가 하나도 없으면 kickoff 날짜로 묶는다. 자료가 «오래된 순» 으로 오니 뒤집어서
        // 최근 경기가 위로 오게 한다. (fixtures 는 round 가 다 있어서 여기 안 걸린다)
        $has_round96 = false;
        foreach ($items as $m96) {
            if (isset($m96['round']) && $m96['round'] !== '') { $has_round96 = true; break; }
        }
        if (!$has_round96 && !empty($items)) {
            $items = array_values($items);
            usort($items, function ($a96, $b96) {
                $ka96 = isset($a96['kickoff']) ? (string) $a96['kickoff'] : '';
                $kb96 = isset($b96['kickoff']) ? (string) $b96['kickoff'] : '';
                return strcmp($kb96, $ka96);
            });
        }
        foreach ($items as $m) {
            $r96 = (isset($m['round']) && $m['round'] !== '') ? $m['round'] : null;
            $key96 = ($r96 !== null)
                ? 'r:' . $r96
                : 'd:' . (isset($m['kickoff']) ? substr((string) $m['kickoff'], 0, 10) : '');
            if (empty($groups) || $key96 !== $last_key96) {
                if ($round_count >= $max_rounds) break;
                $round_count++;
                $last_key96 = $key96;
                $groups[] = ['round' => $r96, 'matches' => []];
            }
            $groups[count($groups) - 1]['matches'][] = $m;
        }
```

`$last_round` 이라는 변수 이름이 `$last_key96` 으로 바뀐 거야. 함수 안에서만 쓰는 변수라
바깥에 영향 없다. `break` · `$max_rounds` · `return $groups;` 는 그대로 둬.

## 3. `lg_page.php` — 469~470행과 531~532행, 두 줄씩
