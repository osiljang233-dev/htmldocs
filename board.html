# 115단계 — 픽 중복을 «넣기 전에» 막는다

★ 파일 하나야. `/var/www/sportsnews/scripts/import-picks-dailypick.php`
★ base **13,654바이트 · 288행 · md5 `10874e33422b34492eb83fe2850b9823`.** 다르면 멈추고 알려줘.
★ 백업 먼저 — `bak15-import-picks-dailypick.php`

★★ **이 판에서 글을 «지우지 마라».** DELETE 를 한 줄도 쓰지 마.
   이미 쌓인 중복은 그대로 둔다. 이 판은 «앞으로 안 쌓이게» 만 한다.

---

## 왜 고치나

지금 같은 경기를 알아보는 열쇠가 이렇게 돼 있어.

```
pick_id = 리그_원정_홈_md5(start_at | verdict) 앞 10자
```

`start_at` 과 `verdict` 는 **자료가 다시 만들어질 때 바뀌는 값**이야.
바뀌면 md5 가 달라지고 → 기존 글을 못 찾고 → **같은 경기가 새 글로 또 들어간다.**

그래서 열쇠를 **안 바뀌는 값**으로 바꾼다 — 리그 · 원정 · 홈 · **경기 날짜**.

---

## 고칠 곳 2군데

### 1) 열쇠 만드는 곳 — 233~238행

**현재 문장**
```php
        if ($pickId === '') {
            $pickId = strtolower((string)($meta['league'] ?? 'pick')) . '_'
                . preg_replace('/[^a-zA-Z0-9]+/', '', (string)($meta['away'] ?? 'a')) . '_'
                . preg_replace('/[^a-zA-Z0-9]+/', '', (string)($meta['home'] ?? 'h')) . '_'
                . substr(md5((string)($meta['start_at'] ?? '') . '|' . (string)($meta['verdict'] ?? '')), 0, 10);
        }
```

**변경 문장**
```php
        /* tg-step115: 열쇠를 «안 바뀌는 값» 으로 바꾼다.
           start_at 시각과 verdict 는 자료가 다시 만들어질 때 흔들려서
           같은 경기가 새 글로 또 들어갔다. 날짜만 쓴다 (시각은 뺀다). */
        $__lg   = strtolower((string)($meta['league'] ?? 'pick'));
        $__away = preg_replace('/[^a-zA-Z0-9]+/', '', (string)($meta['away'] ?? 'a'));
        $__home = preg_replace('/[^a-zA-Z0-9]+/', '', (string)($meta['home'] ?? 'h'));
        $__day  = substr((string)($meta['start_at'] ?? ''), 0, 10);

```

★ `$pickId` 를 **항상** 이 값으로 둔다. 자료에 pick_id 가 들어 있어도 그건 `meta` 에 그대로 남아 있으니 잃는 게 없어.

# 데이터 요청 — 규격서 + 검사기 (2026-08-17)

봇이 보내는 JSON 규격을 문서로 못박았어. 같이 **검사기**도 넣었으니 봇이 보내기 전에
스스로 돌려서 통과한 것만 보내주면 돼. 그러면 우리가 매번 열어볼 일이 없어진다.

## 같이 보내는 것 3개

```
1_읽어주세요.md    이 글
2_데이터규격서.md   ★ 봇이 읽을 규격. 1장=탭별 필드 · 2장=리그·탭 목록
검사.bat           ★ 이것만 부르면 된다
validate.py        검사기 본체
spec.json          규격 원본 (셋을 같은 폴더에 두면 그대로 돈다)
```

## 봇이 할 것

```
검사.bat 보낼파일.json
```

★ **종류를 안 알려줘도 된다.** 파일 안을 보고 알아서 고른다.
★ 그냥 `검사.bat` 만 눌러도 된다. 그 폴더의 `.json` 을 전부 검사한다.
★ **봇에 붙일 때는 종료코드만 보면 된다** — `0` 이면 보내고, `1` 이면 안 보낸다.

통과하면 종료코드 0. 실패하면 **무엇이 어떻게 틀렸는지 · 어떻게 고치는지**까지 찍어준다.
예 — 「46.7 은 퍼센트로 보인다. 0.467 로 보내라」

```
python validate.py --list                 검사할 수 있는 종류 목록 (24가지)
python validate.py --sample soccer_picks  통과하는 예시 파일을 찍어준다
```

```
① 필드 이름을 바꾸지 마라        「선발 ERA」를 「선발평균자책」으로 바꾸면 화면이 빈다
② 못 채우면 null 로 두고         항목 자체는 남겨라. 통째로 빼지 마라
   ★ 그리고 담당자에게 보고해라   말없이 넘기면 아무도 모른다. 화면만 0 으로 뜬다
③ 값 형식을 지켜라              "2.41 vs 5.52" 는 ★ 원정 vs 홈 순서다
```
