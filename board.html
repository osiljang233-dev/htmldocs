# step162 — 네비 301 · 브레드크럼 404 정리 (레프스 건강점수)

파일이 서로 달라서 한 번에 보내. **header.php 2곳 · soccer_board.php 1곳.**
전부 링크 주소(href) 한 조각만 바꾸는 거야. 화면·글자·레이아웃은 그대로.

작업 전에 백업부터 떠줘.

```
cp application/views/front/header.php        application/views/front/bak-ahrefs162-header.php
cp application/views/front/soccer_board.php  application/views/front/bak-ahrefs162-soccerboard.php
```

## 1) header.php — 야구 네비 링크 (base 80,324바이트 · md5 45a997ac380765d191c8169ad0ec6e9a)

749행. 맨 리그 주소라 열면 301로 튕겨서 내부링크가 전부 "리다이렉트로 감"으로 잡혀.
`/lineup` 을 붙여서 바로 도착지로 보낸다.

현재 문장:
```php
                <a href="<?= base_url('news/baseball/' . $__slug) ?>" class="<?= ($active_cat === 'baseball_' . $__slug) ? 'active' : '' ?>"><?= html_escape($__label) ?><?= sn_nchp($__slug, $sn_dday, $sn_on) ?></a>
```

변경 문장:
```php
                <a href="<?= base_url('news/baseball/' . $__slug . '/lineup') ?>" class="<?= ($active_cat === 'baseball_' . $__slug) ? 'active' : '' ?>"><?= html_escape($__label) ?><?= sn_nchp($__slug, $sn_dday, $sn_on) ?></a>
```

바뀐 건 `base_url('news/baseball/' . $__slug)` → `base_url('news/baseball/' . $__slug . '/lineup')` 딱 이거야. active 판정은 손대지 마.

---

## 2) header.php — 농구 네비 링크 (같은 파일 · 위 1번 반영 뒤 이어서)

767행. 같은 문제. 농구는 nba·kbl·wkbl 은 `/lineup`, wnba 만 `/standings` 로 간다.
삼항으로 갈라줘.

현재 문장:
```php
                <a href="<?= base_url('news/basketball/' . $__slug) ?>" class="<?= ($active_cat === 'basketball_' . $__slug) ? 'active' : '' ?>"><?= html_escape($__label) ?><?= sn_nchp($__slug, $sn_dday, $sn_on) ?></a>
```

변경 문장:
```php
                <a href="<?= base_url('news/basketball/' . $__slug . ($__slug === 'wnba' ? '/standings' : '/lineup')) ?>" class="<?= ($active_cat === 'basketball_' . $__slug) ? 'active' : '' ?>"><?= html_escape($__label) ?><?= sn_nchp($__slug, $sn_dday, $sn_on) ?></a>
```

바뀐 건 `. $__slug)` → `. $__slug . ($__slug === 'wnba' ? '/standings' : '/lineup'))` 뿐이야.

## 3) soccer_board.php — 브레드크럼 리그 링크 (base 24,206바이트 · md5 2df49384a914e70040e3fb69fefaf166)

47행. 이 뷰를 야구 픽 탭도 같이 쓰는데 링크에 `news/soccer/` 가 박혀 있어서
MLB 픽에서 `news/soccer/mlb` (없는 주소, 404) 가 찍혀. 축구 보드에선 `news/soccer/epl` (301) 이 찍히고.
같은 파일 79~80행에 이미 올바른 패턴($sport_hub['sport'])이 있으니 그걸 따라가면 돼.

현재 문장:
```php

```

변경 문장:
```php
      <a href="<?= base_url(!empty($sport_hub) ? 'news/'.$sport_hub['sport'].'/'.$sbLg.'/'.$sport_hub['default_tab'] : 'news/soccer/'.$sbLg.'/standings') ?>"><?= html_escape($sbName) ?></a>
```

- 야구/농구 픽(=$sport_hub 있음): `news/baseball/mlb/lineup` 처럼 도착지로 바로. 404 사라짐.

## 1) 626행 — 칼럼 글 메타설명이 너무 짧게 잘리는 것

개별 글 설명을 본문 첫 문장에서 뽑는데, 첫 문장이 20자만 돼도 그걸로 끝내버려서
검색 설명이 30자대로 나가(예: 글 708 = 37자). 최소 길이를 20→90으로 올려서,
첫 문장이 짧으면 본문 앞 150자를 쓰게 해. **새 문구 안 지어내고 본문에서 더 가져올 뿐이야.**

현재 문장:
```php
            if (preg_match('/^(.{20,150}?[.!?](?![0-9])|.{1,150})/u', $plain, $mm)) {
```

변경 문장:
```php
            if (preg_match('/^(.{90,150}?[.!?](?![0-9])|.{1,150})/u', $plain, $mm)) {
```

`{20,150}` → `{90,150}` 숫자만 바꾸는 거야. 나머지 정규식은 그대로.

## 2) 637행 — 경기 글 메타설명 문구 보강

~105자로 늘려. (636행은 그대로 두고 637행만 교체)

현재 문장 (637행):
```php
                . ' 경기 — 두 팀 전력 지표와 최근 기록을 근거 항목까지 함께 정리했습니다. 매일 갱신합니다.';
```

변경 문장 (637행):

                . ' 경기 미리보기 — 두 팀의 전력 지표와 최근 기록, 상대 전적을 근거 항목까지 함께 정리했습니다. 예상 배당과 관전 포인트, 경기 시각도 매일 갱신합니다.';

## 3) 1370행 — 축구 보드 탭(픽·예측·파워랭킹) 제목이 짧은 것

지금 "라리가 픽 - 버저비터"(12자)처럼 라벨만 붙어서 제목이 짧아. 탭 종류별로 설명을 붙여.

현재 문장:
```php
            'title'       => $this->board_labels[$kind] . ' - 버저비터',
```

변경 문장:
```php
            'title'       => $this->board_labels[$kind] . (['picks' => ' | 경기별 분석과 근거', 'predictions' => ' | 경기별 전력 비교', 'power' => ' | 팀 순위 지표'][$tab] ?? '') . ' - 버저비터',
```

- `$tab` 은 이 함수 위(1299행)에서 이미 쓰는 변수야.
- 결과: "라리가 픽 | 경기별 분석과 근거 - 버저비터" / "라리가 예측 | 경기별 전력 비교 - 버저비터" / "라리가 파워랭킹 | 팀 순위 지표 - 버저비터"
