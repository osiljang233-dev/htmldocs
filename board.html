# ① category.php 1057행 — 카드를 «경기일 순» 으로 정렬

## 왜

지금 분석 목록이 **글 등록 순(id 순)** 으로 쌓인다. 그래서 10월 13일 경기가 10월 10일 경기보다 위에 있다.
6건을 한 번에 넣어서 `created_at` 이 전부 같은 탓이다.

바로 위 1053~1054행 주석에 「경기 날짜순으로 쭉 보이는 게 맞다」 라고 적혀 있는데 **정렬 코드가 없다.**

## 현재 문장 — 1057행

```php
            <?php foreach ($__items as $n) { $__an_card($n); } ?>
```

## 변경 문장

```php
            <?php
            /* step238: 경기일 순으로 세운다. 지금까지 글 id 순이라 10/13 이 10/10 위에 있었다.
               앞으로 올 경기  = 가까운 것이 위 (오름차순)
               이미 지난 경기  = 최근 것이 위 (내림차순).  그 아래로 내려간다
               경기일이 없는 글 = 허브 글이다. 맨 뒤로 */
            $__an_key = function ($n) {
                $m = json_decode((string) ($n->meta ?? ''), true);
                $s = (is_array($m) && isset($m['start_at']) && is_string($m['start_at']))
                     ? trim($m['start_at']) : '';
                if ($s === '') return [2, 0];
                $t = strtotime($s);
                if ($t === false) return [2, 0];
                return ($t >= time()) ? [0, $t] : [1, -$t];
            };
            usort($__items, function ($a, $b) use ($__an_key) {
                $ka = $__an_key($a); $kb = $__an_key($b);
                if ($ka[0] !== $kb[0]) return $ka[0] <=> $kb[0];
                return $ka[1] <=> $kb[1];
            });
            foreach ($__items as $n) { $__an_card($n); }
            ?>
```
