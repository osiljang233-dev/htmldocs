# 82단계 — 개막 요약 파일에서 「이미 개막한 리그」를 뺀다

작성 2026-08-16 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 81단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

81단계로 만든 `_openers.json` 에 **이미 개막한 리그가 섞여 있어.**

```
지금 파일   kleague1: 2026-08-15T19:30:00+09:00
실제       ★ K리그1 은 21경기를 치른 시즌 중 리그다
```

이 파일은 **「개막까지 남은 날」** 을 그리는 데 쓰여. 시즌 중인 리그가 들어 있으면
화면에 **「K리그1 개막 D-0」** 이라는 틀린 배지가 붙어.

★ 그 값 자체는 「다음 경기 시각」이라 틀린 게 아니야. **이 파일에 들어갈 게 아닌 것뿐이야.**

```
파일 1개 · 1곳   scripts/import-snapshot-flex.php
```

★ **화면은 안 바뀌어.** 아직 배지가 안 붙어 있어. 파일 내용만 줄어.

### 변경 문장 — 위 2줄을 아래 12줄로 바꿔줘

```php
        $op_j = json_decode(file_get_contents($op_path), true);

        /* tg-step82: 이미 개막한 리그는 안 넣는다.
           이 파일은 「개막까지 남은 날」을 그리는 데 쓴다.

        $op_fx = (is_array($op_j) && is_array($op_j['fixtures'] ?? null)) ? $op_j['fixtures'] : [];
```

### 주의할 점

- **`$op_miss[] = $op_lg;` 를 빼지 말아줘.** 왜 빠졌는지 출력에 남아야 해
- **`continue` 를 빼지 말아줘.** 그게 없으면 그냥 아래로 흘러서 다시 들어가
- `played` 를 `matches` 로 바꾸지 말아줘. **6개 파일 전부 `played` 야.** 실측했어
- **81단계의 `$op_ts <= time()` 검사를 지우지 말아줘.** 이건 다른 검사야
- **80단계 블록(`$kl_` 로 시작)은 손대지 말아줘**
- 변수 이름이 `$op_played` · `$op_s` 야. 다른 `$op_` 변수와 안 겹쳐
- 들여쓰기는 스페이스 8칸 (`foreach` 안이야)

## 주의할 점

- **`+=` 를 `max()` 로 바꾸는 게 A건의 핵심이야.** 판정은 같지만 값이 달라져. 되돌리지 말아줘
- **`$op_season = $op_season + $op_prev;` 의 순서를 바꾸지 말아줘.** PHP 의 `+` 는 «왼쪽» 키를 남겨.
  뒤집으면 옛 값이 오늘 값을 덮어써서 영원히 안 갱신돼
- **`array_merge` 를 쓰지 말아줘.** 문자열 키에서 동작이 달라
- **C건의 칸 이름이 `matches` 야.** 파일 6개(`played`)와 다르니 둘 다 받는 그 줄을 줄이지 말아줘
- **`find_file` 은 이미 있는 함수야** (52행 근처). 새로 만들지 말아줘
- `$dir` 는 이 스크립트가 인자로 받은 unzip 폴더야. **새로 정하지 말아줘**
- **80·81·82단계 블록을 건드리지 말아줘.** 특히 `$kl_` 로 시작하는 부분
- 변수 이름이 `$op_season` · `$op_lg2` · `$op_j2` · `$op_s2` · `$op_p2` · `$op_prev` · `$op_old` · `$op_oldj` 야.
  **앞 단계 변수와 안 겹치게 한 거니 바꾸지 말아줘**
- 들여쓰기는 A·B건이 스페이스 8칸, C·D건이 4칸

```php
    $op_dig = function ($op_node) use (&$op_dig) {
        if (!is_array($op_node)) return 0;
        $op_best = 0;
        $op_isteam = false;

            if (isset($op_node[$op_tk])) { $op_isteam = true; break; }
        }
        if ($op_isteam) {

                if (isset($op_node[$op_gk]) && is_numeric($op_node[$op_gk])) {
                    $op_best = max($op_best, (int)$op_node[$op_gk]);
                }
            }
            if (isset($op_node['rec']) && is_array($op_node['rec'])) {
                $op_rec = $op_node['rec'];
                $op_best = max($op_best, (int)($op_rec['w'] ?? 0) + (int)($op_rec['l'] ?? 0)
                                       + (int)($op_rec['t'] ?? ($op_rec['d'] ?? 0)));
            }
        }
        foreach ($op_node as $op_child) {
            if (is_array($op_child)) $op_best = max($op_best, $op_dig($op_child));
        }
        return $op_best;
    };
    foreach (['championship', 'mls', 'primeira', 'brasileirao', 'eredivisie',
              'mlb', 'kbo', 'npb', 'nba', 'wnba', 'kbl', 'wkbl'] as $op_lg2) {
```
