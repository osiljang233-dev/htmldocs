# 오늘의픽 카운트 바로잡기 + 경기 글 검색 설명 — News.php 세 곳

전부 한 파일이야. `application/controllers/News.php` · base **128,245바이트**.
서로 다른 함수 세 곳이고 앵커 문장이 다 달라서 헷갈릴 일 없어. 순서대로 해줘.

문제 요약:
- 오늘의픽 배지가 실제 카드 수랑 안 맞아. NPB 배지 6인데 카드 4장, MLB 배지 14인데 카드 0장.
  리그 배지만 «날raw 목록»으로 세서 그래. 실제 카드는 시작한 경기를 빼는데 배지는 안 뺐어.
- 경기가 시작되면(킥오프 지나면) 카드에서 바로 빼야 하는데 지금은 «완전히 끝날 때»까지 남아 있어.
- 경기 글(view) 검색 설명이 "결론 OO 승 요약 …"으로 나가서 안 눌려.

---

## 0. 백업 먼저

```
cp application/controllers/News.php application/controllers/bak-News-pickcnt.php
```

---

## 1. 카드 숨김 기준을 «킥오프»로 — dailypick_cards() 안

시작한 경기 픽을 카드에서 바로 뺀다. 홈 히어로랑 같은 기준이야.

### 현재 문장 (전문)

```php
            $status = 'upcoming';
            if ($is_today && $start_ts !== false) {
                $diff = $start_ts - $now;
                $sport = $this->pick_sport_of($meta);
                $game_len = ($sport === 'baseball') ? 12600 : (($sport === 'basketball') ? 9000 : 7200);
                if ($diff <= -$game_len) continue; // 종료 경기(경기시간 다 지난 오늘 픽)는 카드에서 제외
                if ($diff <= 0 && $diff > -$game_len) $status = 'live';
                elseif ($diff <= 1 * 3600 && $diff > 0) $status = 'soon';
            }
```

### 변경 문장 (전문)

```php
            $status = 'upcoming';
            if ($is_today && $start_ts !== false) {
                $diff = $start_ts - $now;
                if ($diff <= 0) continue; // 시작한 경기(킥오프 지난 오늘 픽)는 카드·카운트에서 제외 — 홈 히어로와 같은 기준
                if ($diff <= 1 * 3600) $status = 'soon';
            }
```

`$sport`·`$game_len`·`'live'` 상태는 이제 안 써서 뺐어. 다른 데선 안 쓰던 지역 변수라 괜찮아.

## 2. 리그 배지도 «카드»에서 세기 — category() 안, dailypick 분기

리그 배지(MLB·KBO·NPB…)를 날raw 목록이 아니라 1번에서 거른 카드 목록에서 센다.
종목 배지랑 같은 목록에서 둘 다 뽑게 합쳤어.

### 현재 문장 (전문)

```php
            $league = strtolower((string) $this->input->get('league'));
            $league_counts = [];
            foreach ($day_rows_all as $row) {
                $m = json_decode((string) $row->meta, true);
                if (!is_array($m)) continue;
                if ($sport !== 'all' && $this->pick_sport_of($m) !== $sport) continue;
                $ls = $this->pick_league_slug($m);
                if ($ls === null) continue;
                $league_counts[$ls] = ($league_counts[$ls] ?? 0) + 1;
            }
            if ($league !== '' && $league !== 'all' && isset($league_counts[$league])) {
                $day_rows = array_values(array_filter($day_rows, function ($row) use ($league) {
                    $m = json_decode((string) $row->meta, true);
                    return is_array($m) && $this->pick_league_slug($m) === $league;
                }));
            } else {
                $league = 'all';
            }

            /* 종목별 건수 — 0건인 탭을 눌러도 소용없다는 걸 미리 알린다.
               거르기 전 목록으로 센다. */
            $sport_counts = ['soccer' => 0, 'baseball' => 0, 'basketball' => 0];
            $__cards_for_count = $this->dailypick_cards($day_rows_all, 'time');
            foreach ($__cards_for_count as $__c) {
                $sp = $this->pick_sport_of($__c['meta']);
                if (isset($sport_counts[$sp])) $sport_counts[$sp]++;
            }
```

### 변경 문장 (전문)

```php
            $league = strtolower((string) $this->input->get('league'));
            /* tg-viewcnt: 배지 건수는 «실제 그리는 카드»(dailypick_cards)로 센다.
               전에는 league_counts 를 raw 목록으로 세서, 시작한 경기가 카드에선 빠지는데
               배지엔 남아 NPB 6인데 4장, MLB 14인데 0장처럼 어긋났다.
               종목·리그 배지를 같은 카드 목록에서 둘 다 뽑는다. */
            $__cards_for_count = $this->dailypick_cards($day_rows_all, 'time');
            $sport_counts  = ['soccer' => 0, 'baseball' => 0, 'basketball' => 0];
            $league_counts = [];
            foreach ($__cards_for_count as $__c) {
                $__cm = $__c['meta'];
                $__sp = $this->pick_sport_of($__cm);
                if (isset($sport_counts[$__sp])) $sport_counts[$__sp]++;
                if ($sport !== 'all' && $__sp !== $sport) continue;
                $__ls = $this->pick_league_slug($__cm);
                if ($__ls === null) continue;
                $league_counts[$__ls] = ($league_counts[$__ls] ?? 0) + 1;
            }
            if ($league !== '' && $league !== 'all' && isset($league_counts[$league])) {
                $day_rows = array_values(array_filter($day_rows, function ($row) use ($league) {
                    $m = json_decode((string) $row->meta, true);
                    return is_array($m) && $this->pick_league_slug($m) === $league;
                }));
            } else {
                $league = 'all';
            }
```

## 3. 경기 글 검색 설명 — view() 안

경기 글은 본문 첫머리("결론 OO 승 요약 …") 대신, 제목과 같은 대진+날짜로 설명을 짓는다.

### 현재 문장 (전문)

```php
        if ($plain !== '') {
            if (preg_match('/^(.{20,150}?[.!?](?![0-9])|.{1,150})/u', $plain, $mm)) {
                $settings['seo_description'] = rtrim(trim($mm[1]), ',;:');
            } else {
                $settings['seo_description'] = mb_substr($plain, 0, 150, 'UTF-8');
            }
        }
        $data['settings'] = $settings;
```

### 변경 문장 (전문)

```php
        if ($plain !== '') {
            if (preg_match('/^(.{20,150}?[.!?](?![0-9])|.{1,150})/u', $plain, $mm)) {
                $settings['seo_description'] = rtrim(trim($mm[1]), ',;:');
            } else {
                $settings['seo_description'] = mb_substr($plain, 0, 150, 'UTF-8');
            }
        }
        /* tg-viewdesc: 경기 글은 본문 첫머리('결론 X 승 요약 …')가 검색 설명으로 나가
           라인업·선발 검색의도와 안 맞고 승자 단정처럼 보였다 (view 글 CTR 0.24%).
           제목과 같은 $base105(=대진+날짜)로 설명을 다시 짓는다. 경기 글만 걸린다. */
        if ($__ts92 && !empty($base105)) {
            $settings['seo_description'] = $base105
                . ' 경기 — 양 팀 선발 라인업과 전력, 최근 흐름을 경기 전에 정리했습니다. 매일 갱신합니다.';
        }
        $data['settings'] = $settings;
```

`$__ts92`·`$base105` 는 같은 함수 위쪽 제목 만드는 블록에서 이미 만들어 둔 값이야.
