# 89단계 — 챔피언십 순위표 제목에 「EFL」이 빠져 있다

작성 2026-08-15 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 88단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

챔피언십 네 화면 중 **순위표만 「EFL」이 빠져 있어.**

```
순위표      「챔피언십 순위표 · 팀 순위 · 스포츠 뉴스」        ★ 여기만 EFL 없음
파워랭킹     「EFL 챔피언십 파워랭킹 · 스포츠 뉴스」
예측        「EFL 챔피언십 예측 · 스포츠 뉴스」
픽         「EFL 챔피언십 픽 · 스포츠 뉴스」
```

★ **왜 위험한지.** 「챔피언십」과 「챔피언스리그」는 다른 리그야.

```
챔피언십        EFL Championship — 잉글랜드 2부 리그
챔피언스리그      UEFA Champions League — 유럽 클럽 대항전
```

검색결과에 뜨는 건 `<title>` 이야. 「챔피언십」만 보이면 **챔피언스리그를 찾던 사람이 눌렀다가
2부 리그를 보고 바로 나가.** 클릭은 나는데 이탈하는 조합이라 순위에 제일 나빠.

★ 43단계에서 EFL 표기를 붙일 때 파워랭킹·예측·픽 셋만 바꾸고 순위표가 빠진 거야.

```

화면 변화        ★ h1 과 본문은 그대로.  `<title>` 과 meta description 만 바뀐다
삭제             없다
```

## 왜 하는 작업인지

오늘의PICK 은 **KST 자정이 지나면 어제 픽이 저절로 빠진다.** 그건 이미 잘 돌고 있어.

```

186행   DateTimeZone('Asia/Seoul') 로 못박아 놨다

**문제는 「경기 시각(`meta.start_at`)이 없는 픽」 하나뿐이야.** 292행이 그걸 매일 다시 끼워넣어.

```
지금 화면 12장
  9장   MLB   02:10 ~ 11:10  시각 있음        정상
  2장   K리그1 19:30  (08-05 발행 · 오늘 경기)  정상 — 예약 픽이다
  1장   KBO   ★ 시각 빈 칸 「롯데 자이언츠 @ 키움 히어로즈」
```

그 KBO 픽은 **08-10 부터 6일째 안 내려가.** 자정이 와도 안 빠져. 날짜 바구니에 안 들어가고
`undated` 바구니에 있는데, 292행이 오늘 바구니에 그걸 합쳐버리거든.

★ **덤으로 이것도 같이 고쳐져.** 지금 상단 배지와 화면 장수가 안 맞아.

```
상단 네비 배지    「오늘의 PICK 11」    ← undated 를 안 센다
화면 카드         12장                ← undated 를 끼워넣는다
```

```

현재 크기        85,655바이트 · 1,548행
화면 변화        오늘의PICK 카드 12장 → 11장.  ★ 빠지는 건 시각 없는 KBO 픽 1장뿐
삭제             ★ 없다.  글을 지우거나 내리지 않는다.  화면 한 곳에서만 안 보이게 하는 것

## 주의할 점

- **`+=` 를 `max()` 로 바꾸는 게 A건의 핵심이야.** 판정은 같지만 값이 달라져. 되돌리지 말아줘
- **`$op_season = $op_season + $op_prev;` 의 순서를 바꾸지 말아줘.** PHP 의 `+` 는 «왼쪽» 키를 남겨.
  뒤집으면 옛 값이 오늘 값을 덮어써서 영원히 안 갱신돼
- **`array_merge` 를 쓰지 말아줘.** 문자열 키에서 동작이 달라
- **C건의 칸 이름이 `matches` 야.** 파일 6개(`played`)와 다르니 둘 다 받는 그 줄을 줄이지 말아줘
- **`find_file` 은 이미 있는 함수야** (52행 근처). 새로 만들지 말아줘
- `$dir` 는 이 스크립트가 인자로 받은 unzip 폴더야. **새로 정하지 말아줘**
- **80·81·82단계 블록을 건드리지 말아줘.** 특히 `$kl_` 로 시작하는 부분
- 변수 이름이 `$op_season` · `$op_lg2` · `$op_j2` · `$op_s2` · `$op_p2` · `$op_prev` · `$op_old` · `$op_oldj` 야.
  **앞 단계 변수와 안 겹치게 한 거니 바꾸지 말아줘**
- 들여쓰기는 A·B건이 스페이스 8칸, C·D건이 4칸
