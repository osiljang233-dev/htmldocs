# 91단계 — 픽 글에 「경기 시각」을 찍는다

작성 2026-08-16 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 90단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

픽 글 화면에 **발행일만 있고 「언제 경기인지」가 없어.**

```
지금     2026.08.16 12:00 · 조회 43
바뀔 것   2026.08.16 12:00 · 경기 2026.08.16 03:20 · 조회 43
```

★ **자료는 이미 서버에 있어.** `meta.start_at` 이고, 오늘의PICK 이 그걸로 날짜를 묶어.
39행에서 `$__start_ts` 로 이미 만들어 놨고, 61~67행이 **시각(`H:i`)만** 찍고 있어. 날짜가 없어.

★ **왜 날짜가 필요한가.** 사람이 「이게 오늘 경기야 어제 경기야」를 못 가려.
MLB 는 같은 대진이 사흘 연속 붙어서 `03:20` 만 봐서는 어느 날인지 모르거든.

```
파일 1개 · 1곳   application/views/front/view.php
현재 크기        13,517바이트 · 271행
화면 변화        ★ 발행일 줄에 「· 경기 …」 한 조각이 붙는다.  나머지는 그대로
삭제             없다
사이트맵          194건 그대로.  색인 신호는 안 건드린다
```

# 85단계 — 순위표 접힘 Q&A 를 구글이 「질문과 답」으로 읽게 한다

## 왜 하는 작업인지

리그 순위표 14개 화면에 접히는 Q&A 가 이미 있어. 글은 색인되는데 **구글이 「이건 질문과 답이다」라고 못 읽어.**

```
홈            ld+json 3개  Organization · WebSite · FAQPage    ← 붙어 있다
리그 순위표 14개  ld+json 0개 · details 1 · summary 1           ★ 글은 있는데 표시가 없다
```

`FAQPage` 표시만 붙이면 돼. **글을 새로 쓰지 않아.** 지금 화면에 나오는 그 배열을 그대로 쓴다.

```
파일 1개 · 1곳   application/views/front/_seo_fold.php
현재 크기        19,001바이트 · 283행
화면 변화        ★ 없다.  ld+json 은 눈에 안 보인다
삭제             없다
```

★ **글이 두 벌이 되면 안 돼.** 그래서 새 배열을 만들지 않고 `$__seo_f['qa']` 를 다시 읽어.

### 변경 문장

```php
    ];

<script>
```

# 87단계 — `_latest.json` 의 오늘의PICK 칸이 하루 낡게 나오는 것

작성 2026-08-16 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 86단계까지 다른 코드는 건드리지 말아줘.

## 왜 하는 작업인지

86단계로 만든 `_latest.json` 에서 **오늘의PICK 칸만 하루 낡게 나와.**

```
지금 값   "category_dailypick": "2026-08-14T12:00:00+09:00"     ← 어제
실제      08-15 자 픽 7건 · 08-16 자 픽 13건이 이미 들어와 있다
```

원인은 86단계 보고에 네가 찍어 준 값에 그대로 나와 있어. **PHP 와 MySQL 의 시간대가 다르다.**

```
php_now   2026-08-15T16:13:42+09:00     PHP 는 KST
db_now    2026-08-15 07:13:42          ★ MySQL 은 UTC.  9시간 차이
```

오늘의PICK 의 `created_at` 은 PHP 가 KST 로 넣어 (`08-15 12:00:00`).
86단계에서 「미래 픽을 빼려고」 `created_at <= NOW()` 를 걸었는데,
그 `NOW()` 가 UTC(`07:13`)라 **오늘 픽이 미래로 취급돼 잘렸어.**

```
잘린 것    08-15 12:00 > 08-15 07:13  →  빠진다
남은 것    08-14 12:00                →  이게 최신으로 잡힌다
```

★ **미래 픽을 막는 장치는 그대로 둬야 해.** 안 그러면 내일 경기 픽(08-16) 때문에
늘 「새것」으로 보여. 시각의 기준만 PHP 쪽으로 바꾸면 돼.

```

화면 변화        ★ 없다.  파일 값만 바뀐다
```
