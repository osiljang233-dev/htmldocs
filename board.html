# 랜딩 4개 CTA 주소 교체

랜딩 페이지 안 CTA(본사이트로 가는 `<a href>`) 주소를 바꿔줘.
**`href` 안에 든 것만** 바꾸면 돼. 본문 글자·footer 표기는 건드리지 마.
각 페이지에서 같은 주소가 여러 번(버튼마다) 걸려 있으니 **그 페이지 안에서는 전부** 바꿔줘.

파일이 서로 다르니까 한 번에 같이 해도 돼. 시작 전에 각 파일 백업부터.

---

## 1) 주소왕.org  (현재 약 163,703바이트)

백업: 원본을 `bak-jusoking.org.html` 로 복사.

- 현재:  `href="https://jusoking.co"`
- 변경:  `href="https://주소왕.net"`

이 페이지 안 `href="https://jusoking.co"` 5군데 전부. (nav-btn · btn-main · btn-dark · foot-link · 본문 링크)

---

## 2) 바로주소.org  (현재 약 17,776바이트)

백업: 원본을 `bak-barojuso.org.html` 로 복사.

- 현재:  `href="https://gogojuso.com"`
- 변경:  `href="https://barogogo.com"`

이 페이지 안 `href="https://gogojuso.com"` 5군데 전부.

---

## 3) 주소캠프.org  (현재 약 76,340바이트)

백업: 원본을 `bak-jusocamp.org.html` 로 복사.

- 현재:  `href="https://jusocamp.com"`
- 변경:  `href="https://주소캠프.net"`

이 페이지 안 `href="https://jusocamp.com"` 6군데 전부. (nav-btn · btn-main 2개 · foot-link · 로고 img 링크 · 본문 링크)

---

## 4) 주소일번지.org  (현재 약 22,404바이트)

백업: 원본을 `bak-juso114.org.html` 로 복사.

- 현재:  `href="https://juso114.org"`
- 변경:  `href="https://주소일번지.net"`

이 페이지 안 `href="https://juso114.org"` 5군데 전부.

그리고 footer 에 링크 아니라 **글자로** 박힌 옛 주소도 같이 바꿔줘. 옛 주소는 이제 안 써.
- 현재:  `주소일번지 · juso114.org · 웹툰`
- 변경:  `주소일번지 · 주소일번지.net · 웹툰`

---

## 끝나면 알려줘

- 고친 파일 4개 이름
- 파일마다 바꾼 개수 (예: 주소왕 5군데)
- 바뀐 뒤 href 실제 값 한 줄씩

# KBO 「오늘의 리뷰」 탭 — 라우트·탭·킥커·임포터 배관

KBO 야구에 「오늘의 리뷰」 탭을 새로 깐다. 파일 3개다. 서로 안 겹치니 한 번에 해도 돼.
**각 파일 백업 먼저.** 아래는 전부 "현재 문장 / 변경 문장" 전문이야. 발췌 아님.

★ 전제: 디자인 세션의 뷰 파일 `application/views/front/kbo_review.php` 가 **이미 서버에 올라가 있어야** 이 라우트가 정상 동작해. (없으면 탭 눌렀을 때 뷰 없어서 죽음.) 이 순서는 우리가 맞춰서 보낼게 — 봇은 아래대로만 해주면 돼.

---

## 파일 1) application/controllers/News.php  (base 120,140바이트)

백업: 원본을 `News.php.bak-kboreview` 로 복사.

이 파일에 **4곳** 고친다.

### 1-A. KBO 탭 배열에 review 추가 (1301행 근처)

- 현재:
```php
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'roster' => '로스터', 'starter' => '선발 평가', 'picks' => '픽'],
```
- 변경:
```php
            'tabs' => ['lineup' => '라인업', 'standings' => '순위', 'roster' => '로스터', 'starter' => '선발 평가', 'picks' => '픽', 'review' => '오늘의 리뷰'],
```
★ 이건 kbo 리그 줄(`'kbo' => [ ... ]`) 안의 tabs 야. mlb·npb tabs 는 건드리지 마.

### 1-B. baseball() 의 $kind_map 에 review 추가 (1349행 근처)

- 현재:
```php
            'stats' => 'npb_team_stats',
```
- 변경:
```php
            'stats' => 'npb_team_stats',
            'review' => 'kbo_review',
```

### 1-C. board_labels 에 kbo_review 라벨 추가 (1866행 근처)

- 현재:
```php
        'kbo_roster_changes' => 'KBO 로스터 변경', 'kbo_starter_eval' => 'KBO 선발 평가', 'soccer_absences' => '해외축구 결장자 명단',
```
- 변경:
```php
        'kbo_roster_changes' => 'KBO 로스터 변경', 'kbo_starter_eval' => 'KBO 선발 평가', 'kbo_review' => 'KBO 오늘의 리뷰', 'soccer_absences' => '해외축구 결장자 명단',
```

### 1-D. 전용 뷰로 보내는 분기 추가 (1639행 근처)

- 현재:
```php
        if ($kind === 'kbo_starter_eval') { $this->layout('front/kbo_starter', $data); return; }
```
- 변경:
```php
        if ($kind === 'kbo_starter_eval') { $this->layout('front/kbo_starter', $data); return; }
        if ($kind === 'kbo_review') { $this->layout('front/kbo_review', $data); return; }
```

---

## 파일 2) application/views/front/sport_league_head.php  (base 3,678바이트)

백업: 원본을 `sport_league_head.php.bak2-kboreview` 로 복사.

킥커 맵에 review 추가 (39행 근처, 닫는 `];` 앞).

- 현재:
```php
    'draft_picks'  => 'DRAFT PICKS',
];
```
- 변경:
```php
    'draft_picks'  => 'DRAFT PICKS',
    'review'       => 'REVIEW',
];
```

---

## 파일 3) scripts/import-snapshot-flex.php  (base 54,838바이트)

백업: 원본을 `import-snapshot-flex.php.bak3-kboreview` 로 복사.

job 배열에 kbo_review 한 줄 추가 (401행 근처, kbo_starter_eval 줄 바로 뒤).

- 현재:
```php
    mkFeedJob('kbo_starter_eval_', 'KBO 선발 평가', 'kbo_starter_eval', 'kbo_starter_eval', ['meta.game_date']),
```
- 변경:
```php
    mkFeedJob('kbo_starter_eval_', 'KBO 선발 평가', 'kbo_starter_eval', 'kbo_starter_eval', ['meta.game_date']),
    mkFeedJob('kbo_review_', 'KBO 오늘의 리뷰', 'kbo_review', 'kbo_review', ['date']),
```
