# 91단계 — 픽 글에 「경기 시각」을 찍는다

작성 2026-08-16 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 90단계까지 다른 코드는 건드리지 말아줘.

---

## 왜 하는 작업인지

픽 글 화면에 **발행일만 있고 「언제 경기인지」가 없어.**

```
지금     2026.08.16 12:00 · 조회 43
바뀔 것   2026.08.16 12:00 · 경기 2026.08.16 03:20 · 조회 43
```

★ **자료는 이미 서버에 있어.** `meta.start_at` 이고, 오늘의PICK 이 그걸로 날짜를 묶어.
39행에서 `$__start_ts` 로 이미 만들어 놨고, 61~67행이 **시각(`H:i`)만** 찍고 있어. 날짜가 없어.

★ **왜 날짜가 필요한가.** 사람이 「이게 오늘 경기야 어제 경기야」를 못 가려.
MLB 는 같은 대진이 사흘 연속 붙어서 `03:20` 만 봐서는 어느 날인지 모르거든.

```
파일 1개 · 1곳   application/views/front/view.php
현재 크기        13,517바이트 · 271행
화면 변화        ★ 발행일 줄에 「· 경기 …」 한 조각이 붙는다.  나머지는 그대로
삭제             없다
사이트맵          194건 그대로.  색인 신호는 안 건드린다
```

### 변경 문장

```php
      <p class="hp-ahero__meta">
        <span><?= date('Y.m.d H:i', strtotime($item->created_at)) ?></span>
        <?php /* tg-step91: 경기 시각을 «날짜까지» 찍는다.  $__start_ts 는 39행에서 이미 만든다.
```

# 90단계 — 오늘의PICK 에 날짜 없는 픽이 영원히 붙어 있다

작성 2026-08-15 · 대상 서버 = 버저비터.com (`/var/www/sportsnews`)
**이 1건만 하고 멈춰줘.** 89단계까지 다른 코드는 건드리지 말아줘.

## 왜 하는 작업인지

오늘의PICK 은 **KST 자정이 지나면 어제 픽이 저절로 빠진다.** 그건 이미 잘 돌고 있어.

```
280행   $latest_d = $this->pick_today_kst();     ← 요청마다 KST 오늘을 다시 계산
186행   DateTimeZone('Asia/Seoul') 로 못박아 놨다
HTML    no-store 라 캐시도 안 탄다
```

**문제는 「경기 시각(`meta.start_at`)이 없는 픽」 하나뿐이야.** 292행이 그걸 매일 다시 끼워넣어.

```
지금 화면 12장
  9장   MLB   02:10 ~ 11:10  시각 있음        정상
  2장   K리그1 19:30  (08-05 발행 · 오늘 경기)  정상 — 예약 픽이다
  1장   KBO   ★ 시각 빈 칸 「롯데 자이언츠 @ 키움 히어로즈」
```

그 KBO 픽은 **08-10 부터 6일째 안 내려가.** 자정이 와도 안 빠져. 날짜 바구니에 안 들어가고
`undated` 바구니에 있는데, 292행이 오늘 바구니에 그걸 합쳐버리거든.

★ **덤으로 이것도 같이 고쳐져.** 지금 상단 배지와 화면 장수가 안 맞아.

```
상단 네비 배지    「오늘의 PICK 11」    ← undated 를 안 센다
화면 카드         12장                ← undated 를 끼워넣는다
```

```
파일 1개 · 1곳   application/controllers/News.php
현재 크기        85,655바이트 · 1,548행
화면 변화        오늘의PICK 카드 12장 → 11장.  ★ 빠지는 건 시각 없는 KBO 픽 1장뿐
삭제             ★ 없다.  글을 지우거나 내리지 않는다.  화면 한 곳에서만 안 보이게 하는 것
사이트맵         194건 그대로.  사이트맵은 이 로직을 안 본다
```

★ **그 픽이 갈 데가 없어지는 게 아니야.** `/news/category/dailypick/undated` 전용 화면이
288~289행에 이미 있어서 거기서 볼 수 있어.
